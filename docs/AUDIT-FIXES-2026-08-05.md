## 1. 1차 — 신뢰·안전 (커밋 `3c771f3`)

### 1-1. 동의 저장이 실패해도 「가입 완료」라고 말했다 (P1-4) — 가장 심각

| | |
|---|---|
| 사용자에게 보이던 것 | "가입이 완료되었습니다" 토스트 + 동의창 닫힘 |
| 실제 | 서버에 동의 기록이 없을 수 있음. **분쟁 시 근거가 없는 동의** |
| 원인 | `auth.saveConsent()` 가 Supabase 오류를 `console.warn` 만 하고 정상 반환. 호출자는 성공으로 간주 |
| 수정 | `{ok, reason}` 을 돌려주고, 실패하면 **동의창을 닫지 않고** 재시도 안내. 로컬 동의값도 저장하지 않음 |
| 파일 | `js/auth.js` `js/ui-account.js` |

⚠️ 이건 화면 문제가 아니라 법적 문제라 1차 중에서도 먼저 고쳤습니다.

### 1-2. 기온 화면인데 구름 출처가 표시됐다 (P1-2)

| | |
|---|---|
| 재현 | 지구 → 기온 현재 |
| 실제 | 지구는 기온색인데 좌하단은 `구름 · NOAA GMGSI 전지구 구름 합성` |

| 수정 | **지구를 칠하는 레이어(PAINT)를 먼저** 고름. 위성 영상 → 기상 격자 → 해양 → 구름 순. 점·선 레이어(산불·지진·태풍)는 PAINT 에 넣지 않음 (바탕이 아니므로) |

### 1-3. 안전 자료 장애가 「사건 없음」처럼 보였다 (P1-3)

|---|---|
| 실제 | 지진·쓰나미 수집 실패를 콘솔 경고로만 남김. 빈 지도 = "지금 위험 없음"으로 읽힘 |

⚠️ 성공 중일 때는 아무 줄도 늘리지 않습니다 — 평상시에 줄이 늘면 아무도 안 읽습니다.

### 1-4. 태풍 UI 가 다른 정보창을 가렸다 (P1-1)

|---|---|

## 2. 2차 — 실제로 막히던 흐름 (커밋 `ad82302` `8b73472`)

### 2-1. 검색 결과 일부가 아무 동작도 하지 않았다 (P1-6)

| | |
|---|---|
| 실제 | 없어진 `이벤트`·`하늘` 이 검색에 남아 있고 누르면 검색창만 닫힘. 새 기능 `취미` 는 검색되지 않음 |
| 원인 | `search.js` 에 메뉴와 **별개의 배열**을 손으로 유지 |
| 수정 | 배열을 없애고 **실제 메뉴(`#menuMain [data-act]`)에서 그때그때 읽음.** 메뉴가 곧 목록 |
| 추가 | 실행 대상을 못 찾으면 조용히 return 하지 않고 토스트 + `console.warn` |
| 검증 | 검색 `취미` → 결과 1건 표시 (스크린샷). 죽은 항목 사라짐 |

### 2-2. 항공편이 불가능한 입력을 권했다 (P1-7)

화면 예시는 `예: 인천, ICN` 인데 원본(OurAirports)은 영문만 → 운영에서 `인천` 0건.
→ 한국·일본·중화권 + 한국인이 자주 찾는 노선에 **한국어 별칭** 추가 (약 60개 공항).
`인천`을 치면 ICN 이 코드 다음 우선순위로 올라옵니다.

⚠️ 별칭에 없는 도시는 여전히 영문·코드로만 찾힙니다 — 그 한계는 남아 있습니다.

### 2-3. `if` 지진 답변에 같은 규모가 두 번 (P1-8)

| | |
|---|---|
| 실제 | `M 6.3   M 6.3` — 왼쪽 label 이 이미 규모인데 오른쪽 상세도 규모 |
| 수정 | 오른쪽을 **위치 · 발생 시각**으로 (`_time`, 지역화된 place 키를 실제 필드명으로 읽음) |
| 함께 고침 | 질문은 "오늘"이지만 자료는 **USGS rolling 24-hour feed** → 문장을 `최근 24시간 자료에 지진 52건이 있습니다` 로, 예시 질문도 `최근 24시간 지진 몇 건?` 으로 |

### 2-4. 뉴스가 영원히 로딩 중으로 보였다 (P1-9)

탭 라벨이 `뉴스 …` 로 남음. 원인은 `ui-events.js` 가 탭을 **옛 이름 글자**(`/지역 뉴스|Local news/`)로 찾아 아무것도 못 고치고 있었던 것.
→ `data-tab="local"` **키로** 찾음. 이름을 또 바꿔도 안 깨집니다. `first` 조건도 제거(갱신 때마다 반영).

### 2-5. 가로 화면에서 메뉴가 잘리고 스크롤도 안 됐다 (P1-11)

844×390 에서 `지구` 는 위로, `설정` 은 아래로 잘림. `#menuMain` 이 중앙 정렬 + `overflow:hidden`.
→ `max-height: calc(100dvh - 16px - safe-area)` + `overflow-y:auto` + `overscroll-behavior:contain`.
**검증**: 844×390 캡처에서 `지구` 부터 온전히 보임.

### 2-6. 위치 요청이 두 번 실행되고 기본 위치가 설명 없이 쓰였다 (P1-5)

| | |
|---|---|
| 실제 | `viewer.locateUser()` 와 `mylocation.locate()` 가 **각각** `getCurrentPosition` 호출 |
| 실측 | 시작 시 요청 **2회** (권한창 중복, 좌표 불일치 가능) |
| 수정 | 요청은 `mylocation` 한 곳으로. 이미 받았거나 **이미 거부당했으면 다시 묻지 않음**. `내 위치` 버튼은 사용자가 직접 누른 것이라 `force` 로 재요청 |
| 실측(수정 후) | 요청 **1회** |
| 추가 | 권한이 없으면 첫 화면 도시 이름 옆에 **`기본 위치`** 꼬리표 (전에는 아무 말 없이 인천 날씨를 보여줌) |

⚠️ **첫 수정으로는 부족했습니다.** 공유 promise 만 넣고 측정했더니 여전히 2회 —
첫 요청이 끝난 뒤 부르는 쪽을 못 막았기 때문입니다. 값을 다시 찍어 보고 "거부를 기억한다"까지
넣어서 1회가 됐습니다.

## 3-2. 3차 — 제품 구조 (커밋 `6810938` `4eebac8`)

감사 §9 의 3차 항목 중 **실사용에 직접 걸리는 넷**을 했습니다.

### 3-2-1. 수치 범례 — 색을 칠해 놓고 몇인지 안 알려줬다

감사가 **"Windy 와 비교했을 때 가장 큰 실사용 차이"** 로 지적한 것입니다.
색상·단위 정의는 이미 `js/gridoverlay.js` 의 `SCALES` 에 있었는데 지도 UI 에서 안 썼습니다.

→ 좌하단에 **색 띠 + 눈금(처음·가운데·끝) + 단위**. 화면을 칠할 때 쓴 `scaleOf()` 를
그대로 꺼내 그립니다 — 따로 그리면 화면과 범례가 어긋나는 날이 옵니다.
면을 칠하는 레이어일 때만 나오고, 점·선 레이어(산불·지진·태풍)에는 눈금이 없습니다.

### 3-2-2. 지구를 눌러도 그 자리 값을 말해 주지 않았다

누른 지점의 격자 값을 색 눈금 앞에 굵게 표시 (`28.8°C`).
시트가 안 열리는 Ambient 상태에서도 "지금 여기가 몇 도인가"에 답합니다.

⚠️ **보간하지 않고** 가장 가까운 격자 칸 값을 씁니다 — 없는 정밀도를 만들지 않습니다.
⚠️ 값이 없으면 지웁니다. 옛 값이 남으면 다른 자리 값을 이 자리 값으로 읽습니다.

### 3-2-3. 활성 레이어 바 + 모두 끄기

감사 지적: "바람·산불·태풍을 차례로 켜면 누적되지만 메뉴를 닫으면 무엇이 켜졌는지 알 수 없다."

→ 좌하단에 켜진 레이어 칩 줄 (`기온 × / 태풍 × / 산불 × / 모두 끄기 (3)`).
칩을 누르면 그것만 꺼집니다.

⚠️ 「모두 끄기」도 **하나씩** 끕니다. 상태를 통째로 갈아끼우면 레이어마다 붙어 있는
정리(엔티티 제거)가 안 돌아 지도에 잔상이 남습니다.
⚠️ 기본으로 늘 켜져 있는 구름은 세지 않습니다 — 세면 "항상 1개"가 되어 뜻이 없어집니다.
⚠️ 태풍 타임라인이 뜨면 함께 접힙니다 (1차에서 만든 규칙 재사용).

### 3-2-4. 메뉴 명칭

| 전 | 후 | 이유 |
|---|---|---|
| `지구 스타일` | **`레이어`** | 안에 기온·바람·대기질·바다·관측소가 다 있는데 "스타일"이라 하면 테마 고르는 곳으로 읽힘 |
| `if` | **`물어보기`** | 기능을 추측할 수 없음 |
| `위성` (궤도 메뉴) | **`인공위성`** | `위성`이 날씨 위성 영상과 궤도 위성 둘을 가리키고 있었음 |
| `Alert` (2단 머리글) | **`경보·재난`** | 한국어 화면의 영어 혼재 |

**검증**: 1300×800 · 700×520 · 560×420 에서 기온+산불+태풍을 겹쳐 켜고
칩 3개 + 「모두 끄기 (3)」, 출처가 `기온 · Open-Meteo` 로 맞게 바뀜,
색 눈금 `-50 ~ 10 ~ 50°C`, 지점 값 `28.8°C` 확인.

## 5. 아직 안 한 것 · 다음 감사에서 봐 주셨으면 하는 것

### 5-1. 감사 3차 — 넷은 했고 셋은 안 했습니다

**한 것** (§3-2): 수치 범례 · 지점값 · 활성 레이어 바 · 메뉴 명칭

**안 한 것** — 제품 결정이 필요해 남겨 뒀습니다:

- **빠른 레이어 / 전체 레이어 분리** — 어느 6~8개를 "빠른"으로 올릴지가 제품 결정입니다
- **관측 vs 모델 비교** (부이 실측과 같은 위치·시각의 모델값 대조) — 자료는 있으나
  비교 화면이 없습니다. 감사가 Windy 사례로 제시한 것 중 우리 원칙과 가장 잘 맞습니다
- **레이어 조합 프리셋** (태풍/산불/지진/바다) — 위의 빠른 레이어와 함께 설계해야 합니다

### 5-2. 남아 있는 알려진 한계

| 것 | 상태 |
|---|---|
| 항공편 한국어 검색 | 별칭 약 60개만. 그 밖 도시는 영문·코드로만 |
| 태풍 뉴스 검색 | 일본 매체는 `台風9号` 처럼 번호로 불러 **이름 검색에 안 잡힘**. 화면에 그 한계를 적어 뒀으나 번호 매핑은 없음 |
| 뉴스 내용 | 감사 지적대로 일반 외국어 기사가 섞임. `확인된 지구 사건` 과 `지역 헤드라인` 분리는 미착수 |
| 이용 행태 수집 | 동의는 받는데 **수집 코드가 없음** |
| 에코뱅크 조류 | 자료 108만 건 준비됨(`events/ecobird.json`), 화면 없음 |

### 5-3. 라이선스 — 판매 전 결정 필요

운영자(PD) 사업 모델: **1차 수집 자료는 무료 배포, 2차 가공(분석 문서)만 유료.**

이 구조에서 대부분 자료는 문제없습니다 — 상업 이용이 명시적으로 허용된 것들입니다:

| 자료 | 라이선스 |
|---|---|
| 해양수산부 국가해양생태계종합조사 (바닷새) | 공공누리 — 이용허락범위 제한 없음 |
| 농림축산검역본부 (철새) | 공공누리 — 제한 없음 |
| NOAA IBTrACS (태풍 1,477개) | 퍼블릭 도메인 |
| NASA GIBS (위성 영상) | 퍼블릭 도메인 |
| ECMWF (모델 예보) | CC-BY-4.0 |

⚠️ **Open-Meteo 하나만 남습니다.** 무료 엔드포인트는 비상업용이고, 판단 기준은
"그 기능이 무료인가"가 아니라 **"그 데이터가 유료 산출물의 재료로 들어갔는가"** 입니다.
유료 분석 문서를 위 상업 허용 자료로만 만들거나, `customer-api.open-meteo.com` 으로
전환하면 해소됩니다. `SALES_OPEN=true` 를 여는 시점의 선행 조건으로 잡아 뒀습니다.

미확인: 에코뱅크(국립생태원 오픈API), GDACS(EU JRC), GEMS(천리안2B) 이용조건.

### 5-4. 감사자께 부탁드리는 관점

이번 감사가 특히 유용했던 이유는 **"조용히 잘못 표시되는 것"** 을 잡았기 때문입니다
(콘솔은 깨끗한데 화면이 거짓말하는 것). 다음에도 그 관점을 부탁드립니다:

1. **화면의 값과 그 옆에 적힌 출처·시각이 실제로 같은 자료인가** — 이번에 기온/구름에서 걸렸습니다
2. **빈 것이 "없음"인지 "못 받음"인지 구별되는가** — 안전 정보에서 가장 위험합니다
3. **성공했다고 말하는 자리가 정말 성공했는가** — 동의 저장이 그랬습니다
4. **손으로 유지하는 목록이 실제와 어긋난 곳** — 검색 목록·뉴스 탭 이름·출처 우선순위가
   전부 같은 뿌리였습니다. 아직 남아 있을 수 있습니다
5. 원칙(§0) 위반 — 특히 예보처럼 읽히는 문장, 자료 없이 그린 도형
