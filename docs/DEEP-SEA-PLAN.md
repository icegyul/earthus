# 심해 잠수 — 개발 계획 (검토판)

작성 2026-08-07 · 판단·계획 Claude(Fable) / 제작 Codex
받은 요청: "심해도 만들고 싶어. 위치에 따라 물고기·고래가 다르고, 해구 깊이도
다르고, 심해로 들어가면 메뉴도 다르게."
받은 방향: **우주와 심해는 교육 영역** — SPACE-ZOOM-PLAN.md 와 쌍둥이 기획이다.

---

## 0. 결론 먼저

**우주 계획과 같은 방식 — "잠수 사다리" + 장면 전환.** 3D 물속 렌더링은 안 한다.

- 바다를 탭하면 뜨는 지점 시트(이미 있음 — `isOcean` 판정 + 파고 조회)에
  **"🤿 여기서 잠수"** 버튼 하나를 붙인다. 진입점 공사가 거의 없다.
- 잠수하면 **그 지점의 수심 기둥(세로 단면)** 을 2D 캔버스로 내려간다.
  깊이에 따라 어두워지고, 그 지점의 **실제 해저 수심**(GEBCO)에서 바닥에 닿는다.
- 생물은 **"여기 산다"가 아니라 "여기서 관측된 기록이 있다"** 로만 말한다 (OBIS).
  이게 이 기능의 정직성 전부다 — 철새 레이어("날아간 길이 아닙니다")와 같은 문법.
- **차별점**: 유명한 심해 스크롤 사이트들은 어디서나 똑같은 하나의 심해다.
  우리는 **지구본에서 고른 그 지점**의 실제 수심·실제 관측 기록으로 그린다.
  서해에서 잠수하면 100m 도 안 돼 바닥이고, 마리아나에서 잠수하면 11km 를 내려간다.
  그 차이 자체가 콘텐츠다.

## 1. 정직성 원칙 ⚠️

| 항목 | 원칙 |
|---|---|
| 생물 표시 | OBIS 는 **과학자가 우연히 그물을 던진 곳의 기록**이지 전수조사가 아니다. 연안·표층은 기록이 많고 심해는 거의 없다 — "관측 기록 N건" 으로만 말하고, 기록이 없는 곳은 **"기록 없음 ≠ 생물 없음"** 을 화면에 적는다 |
| 심해 미탐사 | 인류는 심해저의 대부분을 직접 본 적이 없다. 이건 감출 약점이 아니라 **그 자체가 교육 콘텐츠다** — "여기부터는 인류가 거의 가 보지 못한 곳입니다" 카드. coverage 레이어("자료가 없는 곳을 보여주는 레이어")와 같은 철학 |
| 실시간 고래 위치 | **존재하지 않는 데이터다.** 표지(태그) 단 개체 몇 마리뿐. "지금 여기 고래가 있다"는 화면은 만들지 않는다. 이동 시기·해역 카드로만 |
| 수심 값 | GEBCO 격자값 — 해상도(약 450m)와 출처를 표기. 해구 최심부는 **측정마다 다르다** (챌린저 해연 10,902~10,935m) — 한 값으로 단정하지 않고 "약 10,9xx m · 측정마다 다름" |
| 생물 사진 | Wikimedia Commons 는 **장마다 라이선스가 다르다** — 한 장씩 확인·크레딧 필수. NOAA 탐사 사진은 퍼블릭 도메인(크레딧 표기). 우주 사진과 같은 규율: 크레딧 없으면 카탈로그에 못 들어간다 |
| 용어 | 쉬운 말 원칙 — "햇빛이 닿는 층(~200m)" · "어스름한 층(200~1,000m)" · "빛이 없는 층(1,000m~)" 처럼 풀어 쓰고 학술명·숫자는 괄호에 |

## 2. 잠수 사다리

```
D0 바다 표면    지금 앱 (SST·파고·부이·해류)
─── "🤿 여기서 잠수" — 장면 전환 (1.2초, 수면을 뚫는 연출) ───
D1 수심 기둥    그 지점의 세로 단면. 내려갈수록 어두워짐
                · 0~200m    햇빛이 닿는 층 — 관측 기록 생물, 수온(부이 실측 연동)
                · 200~1,000m 어스름한 층 — 여기부터 "햇빛의 1% 미만" 표기
                · 1,000m~    빛이 없는 층 — 발광 생물, 압력 카운터(10m당 1기압)
                · 바닥       그 지점 실제 수심(GEBCO)에서 정지 — "여기가 바닥입니다"
D2 해구 스페셜  주요 해구 ~10곳에서만 열리는 연장 구간 (마리아나 등)
                비교 오브젝트: 에베레스트를 거꾸로 넣어도 2km 남는다, 타이타닉(3,800m),
                향유고래 잠수 한계, 민부리고래 기록(~3,000m — 포유류 최심 잠수)
D3 우리 바다    한국 특화 카드 — 서해는 왜 얕은가, 동해는 얼마나 깊은가
                (⚠️ 수치는 큐레이션 때 출처 확인 — 지금 단정하지 않는다)
```

### 깊이 자 = 스케일 자의 아래쪽 연장

우주 계획의 스케일 자와 **하나로 잇는다**: 은하 — 태양계 — 지구 — 수면 — 해구.
"위로 138억 광년, 아래로 11km" — 이 한 줄이 두 기능을 묶는 브랜드 문장이 된다.
자에서 위를 누르면 우주로, 아래를 누르면 잠수로.

## 3. 데이터 계획

| 자료 | 원천 | 방식 | 판정 |
|---|---|---|---|
| 해저 수심 | **GEBCO 2024** (무료·출처표기) | Lambda `ocean-depth`: 원본(~7GB)을 내려받아 축소 격자를 S3 에 굽고, 지점 질의는 spot-air 패턴으로 응답 | ✅ 핵심. 런타임 외부호출 0 |
| 생물 관측 기록 | **OBIS** (api.obis.org — 유네스코 IOC, 무료·키 없음) | ⚠️ 런타임 직접 호출 금지(느리고 무거움). Lambda 가 해역별 요약(종 수·대표종·기록 수)을 미리 굽는다 | ✅ 2단계 |
| 생물 도감 | 손 큐레이션 **~80종** (고래류·유명 어류·두족류·심해 발광 생물) + 깊이 범위 | 우주 사진 50장과 같은 방식 — 첫 판은 손으로, 한 종씩 사진 라이선스 확인 | ✅ 1단계 |
| 종 상세(깊이·크기) | FishBase / SeaLifeBase | ⚠️ 커뮤니티 미러 API 라 연속성 불확실 — 큐레이션 보조로만, 런타임 의존 금지 | 보조 |
| 해구 목록 | 손 큐레이션 ~10곳 (마리아나·통가·필리핀·일본·쿠릴·케르마덱·푸에르토리코 등) | 정적 JSON. 최심부 값은 범위로 표기 | ✅ |
| 수온 단면 | 부이 실측(표층, 이미 있음) + World Ocean Atlas 기후값(깊이별) | WOA 는 후순위 — 없어도 D1 은 성립 | 나중 |
| 기존 자산 연동 | 바다거북 경로·바닷새·부이·SST — 이미 앱에 있음 | 잠수 씬에서 "이 해역의 바다거북 기록 보기" 링크 | ✅ 공짜 |

새 Lambda 는 둘: `ocean-depth`(수심 격자 굽기+지점 질의) · `obis-summary`(주 1회 해역 요약).

## 4. 렌더링 — 왜 3D 를 안 하나

- 물속 3D 는 게임 엔진 영역이다 — 볼륨 안개·산란광·생물 모델. 예쁘게 하려는 순간
  발열 규율이 무너지고, 어설프게 하면 없느니만 못하다.
- **수심 기둥은 2D 캔버스 한 장**이다: 배경 그라데이션(깊이별 색) + 생물 스프라이트
  (깊이 범위에 맞는 자리) + 깊이 눈금 + 압력·빛 카운터. 스크롤(휠/드래그)로 내려간다.
- 애니메이션 규율: 하강 중에만 그린다. 멈추면 정지 화면 (requestRender 문법 그대로).
- 전환 시 Cesium 은 렌더 중단·숨김 (우주 계획 §4 와 동일 — 파괴하지 않는다).
- 생물 스프라이트는 실사 썸네일(우리 S3 캐시) — 일러스트를 새로 그리지 않는다.

## 5. 메뉴 — 잠수하면 이렇게 바뀐다 (받은 질문)

우주 메뉴와 같은 원칙: **갈아치우지 않고 거른다 · 지구(수면) 레이어는 접어서 보존 ·
안전 감시 유지.** 특히 쓰나미 배너는 바닷속에서 더 의미 있다 — 누르면 수면 복귀.

### 항상 남는 것
검색 · 설정 · **수면으로 돌아가기**(맨 위 고정) · 깊이 자 · 안전 배너

### 잠수 중 메뉴 (2단 시트)

| 그룹 | 항목 | 비고 |
|---|---|---|
| **생물** | 고래·물범류 / 물고기 / 오징어·문어 / 심해 생물 / 발광 생물 | 토글 = 기둥에 그 묶음 표시. 각 항목에 "관측 기록 기반" 문구 |
| **깊이 이동** | 햇빛층 → 어스름층 → 무광층 → 바닥 → (해구에서만) 최심부 | 누르면 그 깊이로 스크롤 |
| **표시** | 압력·수온 / 비교 오브젝트(타워·타이타닉·에베레스트) / 깊이 눈금 | |
| **알아보기** | 이 지점 카드(수심·해역명) / 왜 어두운가 / 인류는 어디까지 가봤나 | 콘텐츠 카드 — 레이어 아님 |
| ▸ 접힘 | "수면 레이어 N개 켜짐 · 돌아가면 보입니다" | 상태 보존 |

### 하단 빠른 칩
🐋 고래 · 🐟 물고기 · ✨ 발광 생물 · 📏 비교 · (해구에서만) 🕳️ 최심부로

### 생물 정보창 (스프라이트 클릭 — 기존 시트 틀)
사진 · 이름(국명+학명) · 관측 깊이 범위 · **이 해역 관측 기록 N건 (OBIS)** ·
크기 비교(사람 실루엣 옆에) · 사진 크레딧

## 6. 구현 순서

| 단계 | 내용 | 완료 조건 | 추정 |
|---|---|---|---|
| **P0 스파이크** | GEBCO 축소 격자 굽기 + 지점 수심 질의 Lambda + 마리아나·서해·동해 3점 검증 | 알려진 수심과 대조 통과 | 반나절 |
| **P1 수심 기둥** | 잠수 버튼 + 하강 씬(깊이층·압력·빛·바닥) — **생물 없이도 성립** | 서해(얕음)와 마리아나(깊음)가 실제로 다르게 내려감 | 2일 |
| **P2 생물 도감** | 손 큐레이션 80종 + 깊이 배치 + 정보창 | 사진 크레딧 전수 확인, 언어 2종 | 2일 |
| **P3 해구 스페셜 + 우리 바다** | 해구 10곳 연장 구간 + 비교 오브젝트 + 한국 카드 | 최심부 값 범위 표기 | 1일 |
| **P4 OBIS 연동** | 해역별 관측 요약("이 해역 기록 N건") | "기록 없음 ≠ 없음" 문구 필수 | 1~2일 |
| **P5 메뉴·깊이 자·발열 검증** | 우주 스케일 자와 통합 | 정지 시 GPU 유휴 | 1일 |

P1 만으로 배포 가치가 있다 — "내가 고른 바다의 진짜 깊이를 내려가 본다".
생물(P2)은 그 다음이다.

## 7. 리스크

| 리스크 | 대응 |
|---|---|
| OBIS 응답이 크고 느림 | 런타임 호출 금지 — Lambda 사전 요약으로만 |
| 생물 사진 라이선스 혼재 | 종당 1장씩 사람이 확인. 크레딧 없으면 탈락 (Lambda 필수 필드 검사) |
| "여기 산다" 오해 | 모든 생물 표시에 "관측 기록" 문구 + 기록 없음 ≠ 없음 카드 |
| 수치 단정 (해구 깊이·동해 수심) | 범위 표기 + 큐레이션 때 출처 확인. 이 문서의 수치도 확정 아님 |
| 우주와 동시 개발로 분산 | **우주 P1(사진) 먼저, 심해 P1(수심 기둥) 다음** — 장면 전환·스케일 자 코드를 우주에서 만들고 심해가 물려받는다 |

## 8. 하지 않는 것

- 3D 물속 렌더링 · 잠수함 게임화
- 실시간 고래 위치 (데이터가 존재하지 않는다)
- 가상 생물·과장된 크기 연출
- FishBase 런타임 의존
- 전 지구 해저 지형 3D 타일 (ion 의존 + 무거움 — 수심 기둥이면 충분)

## 9. 전략 — 교육 영역 (받은 방향)

우주와 심해는 **"경이로움 축"** 으로 한 묶음이다. 태풍(하늘) → 우주(위) → 심해(아래).

- 전부 무료 공개 데이터 — **유료화 대상이 아니라 브랜드·교육 자산.**
  TIER_RATIONALE 에 이미 "3D 학습은 계속 무료"로 선언돼 있다 — 그 안에 들어간다.
- NIA 계획서의 교육 축("글이 아니라 돌려 보면서 알게")의 세 번째 물건.
- 공유 인프라: 장면 전환기·스케일(깊이) 자·큐레이션 카탈로그 Lambda 패턴 —
  우주에서 먼저 만들고 심해가 재사용한다. **두 기능이지만 공사비는 1.5개분이다.**
