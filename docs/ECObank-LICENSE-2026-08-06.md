    공공이용 표시가 없는 자료는 권리자 허락 또는 담당자 협의가 필요하다.

  - 속성 자료는 XML·JSON, 공간 자료는 WMS·WFS로 외부 활용할 수 있다.

## 2. earthus 운영 판정

| 사용 방식 | 현재 판정 | 이유 |
|---|---|---|
| 출처·관측시각·표본 수를 밝힌 무료 5km 집계 지도 | **제공 유지** | 공공누리 제1유형과 외부 활용용 API 표시가 있음. 다만 제3자 권리 포함 경고를 화면에 함께 둔다. |
| 유료 회원에게 5km 격자·종별 집계를 제공 | **서면 확인 전 보류** | 제1유형은 상업·가공을 허용하지만, 제3자 권리가 걸린 레코드·필드를 earthus가 구분할 수 없음. |
| earthus가 계산한 집계 CSV 내보내기 | **서면 확인 전 보류** | 가공통계의 제3자 제공 범위와 필요 출처 문구를 확인해야 함. |
| 건별 위치·종명 원자료 CSV/API 재배포 | **보류** | 원 API 대체 서비스가 되고 제3자 권리 자료까지 재배포할 위험이 가장 큼. |
| 원자료 장기 캐시·스냅샷 판매 | **보류** | 로그인 뒤 활용 신청 약관에서 캐시·보관 범위를 공개적으로 확인하지 못함. |

`SALES_OPEN=false`를 유지한다. 이 판정은 “상업 이용 금지”가 아니라 **제3자 권리 범위가
확인되지 않은 데 따른 제품 잠금**이다.

정책으로 가는 링크를 함께 제공한다.

## 4. 서면으로 확인할 질문

담당자에게 다음 질문의 답을 받아 이 문서에 날짜·답변자·원문 보관 위치를 추가한다.

1. `제3자 권리 포함`이 특정 레코드나 필드를 가리키는지, 해당 범위를 식별할 메타데이터가 있는지.
2. earthus가 건별 위치를 노출하지 않고 약 5km 격자로 계산한 건수·종 수를 유료 회원에게
   제공할 수 있는지.
3. earthus 집계 결과만 CSV로 제공할 수 있는지. 원본 레코드를 포함하지 않아도 추가 출처
   문구나 제한이 필요한지.
4. OpenAPI 응답을 earthus 서버에 장기 보관하거나 일자별 스냅샷으로 보관해도 되는지.
5. 서비스와 내보내기 파일에 넣어야 하는 정확한 출처·저작권 표시 문구가 무엇인지.

답을 받기 전에는 외부로 문의를 자동 발송하지 않고, 문의 초안까지만 준비한다.
