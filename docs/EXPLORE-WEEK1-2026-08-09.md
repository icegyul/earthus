# 우주·심해 탐험 1주차 실행 기록

작성 2026-08-09 · A1·A2 첫 운영 배포

## 이번에 된 것

- `scene.js`: `earth | space | ocean` 상태와 1.2초 CSS 크로스페이드.
- 지구를 떠날 때 Cesium을 파괴하지 않고 입력을 막아 숨기며, `power.suspend()`로
  남은 렌더 예약을 거둔다. 지구 복귀 때 입력·렌더를 다시 깨운다.
- 장면 상태는 저장하지 않는다. 새로고침 뒤 운영 화면이 `earth`에서 시작함을 확인했다.
- `ui-scale.js`: 은하들→은하수→태양계→달→지구→수면→해구 공용 자.
  지구에서는 접혀 있고 우주·심해에서는 자동으로 펼쳐진다.
- 재난 배너 클릭은 `sceneMgr.to('earth')`가 끝난 다음 기존 `go()`를 실행하도록 배선했다.
- 카메라 조작 상한을 45,000km에서 2,000,000km로 올려 B0 줌아웃 실험 길을 열었다.
- 새 장면 문구는 ko·en 쌍으로 넣었다. 우주·심해 교육 영역은 계속 무료다.

## 검증

- 수정 JS 8개 `node --check` 통과, `git diff --check` 통과.
- 로컬 브라우저: 지구 초기 상태 → 우주 `solar` → 심해 `trench` → 지구 복귀 통과.
- 로컬 검수 캡처: 기본 지구, 확장 줌아웃 지구, 우주 스케일 장면 3장 확인.
- 운영 브라우저: 지구 초기 상태, 우주 `solar`, 지구 복귀 통과. 콘솔 오류 0건.
- 운영 배포 10파일은 캐시 우회 응답의 SHA-256이 로컬과 전부 일치했다.
- CloudFront 무효화 `ICY4TCCZOWMT0W7LLBMOA063OG` 생성. 이 배포 계정에는
  `GetInvalidation` 권한이 없어 상태 조회 대신 운영 파일 SHA와 화면으로 확인했다.

## 아직 안 된 것

- B0 북극성 RA·Dec의 ICRF→지구고정 방향 대조와 행렬 `undefined` 폴백.
- 구형 폰에서 전환 후 정지 GPU 유휴 실측. 데스크톱에서는 무한 타이머·프레임 루프가
  새로 생기지 않았음을 코드와 콘솔로 확인했지만, 이를 폰 실측으로 바꿔 말하지 않는다.
- 실제 재난 항목이 떠 있는 상태의 배너 클릭 화면 검수. 복귀 배선은 들어갔지만
  검수 시점에 누를 운영 경보가 없어 활성 항목 테스트는 다음 안전한 테스트 픽스처에서 한다.
- 우주 사진·태양계·실제 수심 콘텐츠. 현재 장면은 공통 전환 기반임을 화면에 명시한다.
