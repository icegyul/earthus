# 우주·심해 탐험 6주차 메뉴 마감 기록

작성 2026-08-10 · 장면별 메뉴 필터 첫 운영 단위

## 이번에 된 것

- 우주·심해 장면에서 지구 전용 조작을 그대로 늘어놓지 않고 장면에 맞게 접었다.
  우주에는 인공위성, 심해에는 바다 조건으로 이어지는 취미를 남겼다.
- 안전·뉴스·LAB·질문·설정은 어느 장면에서도 접근할 수 있다. 특히 Alert를 장면
  필터로 숨기지 않았다.
- 켜져 있던 지구 레이어는 끄지 않고 `지구 레이어 N개 켜짐` 한 줄로 표시한다.
  이 줄을 누르면 지구로 돌아온 뒤 기존 레이어 패널을 바로 연다.
- 우주·심해 장면이 메뉴보다 위에 있어 손잡이를 눌러도 열리지 않던 z-index 오류를
  고쳤다. 메뉴는 장면 위, 재난 배너 아래에 둔다.

## 검증

- `layerbar.js`를 ES 모듈로 복사해 `node --check` 통과.
- `python3 tools/validate_catalogs.py --require-populated --space-min 50` 통과.
- 1280px 우주 장면: 지구 레이어 접힘 줄·인공위성·Alert·설정 노출, 지구 전용
  위치/전지구/취미 항목 비노출을 확인했다.
- 접힘 줄 클릭: 지구 복귀, 기존 레이어 패널 열림, 레이어 상태 보존을 확인했다.
- 390×844 심해 장면: 접힘 줄·Alert·뉴스·LAB·질문·취미·설정만 표시되고 인공위성·
  위치·전지구 항목은 숨겨졌다. 가로 넘침 0px, 메뉴 전체가 화면 안에 들었다.
- 새 콘솔 오류가 없음을 확인했다.

## 아직 안 된 것

- 실제 구형 아이폰에서의 정지 GPU 유휴·발열 실측은 하지 않았다. 코드상 장면 메뉴는
  새 rAF·타이머를 만들지 않지만 이를 실기기 결과로 바꿔 말하지 않는다.
- 제임스웹 L2 부근과 보이저 1·2호 위치 표시는 사양만 있고 아직 구현되지 않았다.
  다음 제작 단위는 JPL Horizons 상태벡터를 먼저 확보·검증한 뒤 진행한다.
