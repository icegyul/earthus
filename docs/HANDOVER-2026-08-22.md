## 9. 이 자료만으로 재개발할 수 있는가

### 가능한 범위

Git 저장소와 이 인수인계 묶음만으로 정적 앱 구조, 화면·레이어 코드, Lambda·Supabase 코드,
테스트, 배포 절차와 미완료 계획을 파악해 **로컬 재개발을 이어갈 수 있다.** 시작점은 이 문서,
누적 판단 근거는 `HANDOVER.md`, 기능별 계약과 운영 증거는 연결된 `docs/` 문서다.

### 별도로 필요한 운영 자산

다음은 보안·권리 때문에 Git과 인수인계 문서에 값 자체를 넣지 않는다.

- AWS·CloudFront·Supabase·도메인 계정 권한과 실제 비밀값
- 공급자 API 키, OAuth 앱 심사·토큰, 결제 사업자 설정
- 운영 DB의 현재 schema/data 백업과 실제 테스트 계정
- 라이선스 승인이 필요한 원본 자료와 실기기 검수 결과
- 저장소 밖 `earthus-local-data/`, `earthus-local-assets/`의 대용량 원본

따라서 문서만으로 **코드 재개발은 가능**하지만, 운영 서비스를 똑같이 복구하거나
`E2E_ACCEPTED`로 판정하려면 위 외부 자산을 별도로 인계받아 다시 검증해야 한다.
