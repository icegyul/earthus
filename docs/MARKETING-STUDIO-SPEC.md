# 마케팅 스튜디오 — 제작 지시서

> 대상: 이 작업을 이어받는 개발자 또는 AI(코덱스 등)
> 작성: 2026-08-05 · 상태: **1단계 운영 중. 2026-08-10 2단계 코드·Edge Function 배포, 실제 SNS 자격증명 검증 남음.**
> 만들 것: `prototype/studio.html` — 릴스·카드뉴스를 만들고 배포까지 하는 화면

## 0. 시작하기 전에

**먼저 [`docs/HANDOVER.md`](./HANDOVER.md) 를 읽으세요.** 배포 방법·코드 규칙·이미 밟은
함정이 거기 있습니다. 이 문서는 그것을 안다고 보고 씁니다.

이 화면에만 적용되는 절대 규칙이 하나 있습니다.

> ### ⚠️⚠️ 자동으로 게시하지 않는다
>
> 초안을 만드는 것까지가 기계의 일이고, **올리는 손은 사람이 댄다.**
> 이유는 감정이 아니라 실측이다 — 하루 만에 이런 것을 찾았다:
> · NHC 경도 부호가 빠져 **동태평양 허리케인이 서태평양에 찍혔다**
> · 파고를 최대가 아니라 평균으로 보여줘 **2.3배 작게** 나갔다
>
> 화면 오류는 고치면 되지만 **게시물은 이미 퍼진 뒤다.**
> 이 규칙을 깨는 PR 은 기능이 좋아도 받지 않는다.
> (`aws/social-draft/handler.py` 머리말에 같은 내용이 있다)

"자동 배포"라는 말은 이 문서에서 **"사람이 확인 버튼을 누르면 여러 채널에 한 번에
올라간다"** 는 뜻이다. 사람 없이 올라간다는 뜻이 아니다.

## 1. 왜 관리자 페이지에서 떼어내나

`admin.html` 은 **운영 상태를 보는 곳**이다(회원 수, 결제, 개발 목록).
마케팅은 **매일 손으로 만드는 작업**이라 성격이 다르다. 한 화면에 두면
둘 다 지저분해지고, 나중에 마케팅만 다른 사람에게 맡기기도 어렵다.

→ `prototype/studio.html` 로 새로 만든다. 로그인·관리자 판정은 `admin.html` 과
같은 방식을 그대로 복사한다(§7).

## 2. 이미 있는 것 (새로 만들지 말 것)

| 있는 것 | 무엇 | 어디 |
|---|---|---|
| **초안 생성기** | 태풍 상황이 바뀌면 사실+문구+카드 사양을 만들어 S3 에 쌓는다 | `aws/social-draft/handler.py` |

| **화면 캡처 방법** | 헤드리스 크롬 + 소프트웨어 WebGL 로 실제 화면을 찍는 절차 | [`docs/talk/capture.md`](./talk/capture.md) |
| **카드뉴스 원고** | "태풍 0개" 8장 + 숫자 검증표 | [`docs/marketing/typhoon-zero-cards.md`](./marketing/typhoon-zero-cards.md) |
| **관리자 인증** | 로그인 + UID 대조 | `prototype/admin.html` |
| **브랜드** | 색·타이포·로고 | `docs/talk/img/brand-sheet.png` |

편이 낫다.** 그래서 초안은 "사실 + 문구 + 카드 사양"이고 그림은 이 화면이 그린다.

## 3. 초안 자료 구조 (실측)

`https://earthus.net/events/social-drafts.json`

```
{ generated, count, source, note,
  drafts: [{
    id      "CHAN-HOM-202608052028"      // 태풍키-시각. 같은 사건 중복 방지용
    at      "2026-08-05T20:28:23+09:00"
    storm   "CHAN-HOM"
    name    "Chan-hom"
    kind    "update"                      // 사건 종류
    facts   { key, name, agencies:[...] } // 검증된 사실 — 문구의 근거
    card    { title, sub, rows:[{k,v}] }  // 카드에 그릴 것
    text    { x, threads, ... }           // 채널별 문구 (줄바꿈 포함)
    posted  {}                            // ⚠️ 어디에 올렸는지 — 지금은 비어 있다
  }]
}
```

⚠️ `posted` 를 채우는 것이 이 화면의 일 중 하나다(§6).

## 4. 만들 화면

### 4-1. 전체 구조

```
studio.html
 ├ 잠금 (로그인 + 관리자 UID 확인)          ← admin.html 복사
 └ 탭 3개
    ├ ① 초안        social-drafts.json 목록 → 고르면 아래 둘로 보낸다
    ├ ② 카드뉴스    1080×1080 / 1080×1350 여러 장 → PNG 내려받기
    └ ③ 릴스        1080×1920 연속 캡처 → 프레임 묶음 또는 WebM
```

### 4-2. ① 초안 탭

- `social-drafts.json` 을 받아 카드로 나열 (최신순)
- 각 초안에 `facts` 를 **펼쳐 볼 수 있게** 둔다 — 문구가 어디서 나왔는지 사람이 확인해야 한다
- 「카드뉴스로」 「릴스로」 두 버튼
- ⚠️ `posted` 에 이미 기록이 있으면 **「올린 적 있음」 표시**를 크게 — 중복 게시가 제일 흔한 사고다

### 4-3. ② 카드뉴스 탭

**규격**

| 채널 | 크기 | 비고 |
|---|---|---|
| X (트위터) | 1600×900 | 가로. 타임라인에서 잘리지 않는다 |
| 스레드·인스타 | 1080×1350 | 세로 4:5. 화면을 가장 많이 먹는다 |
| 정사각 | 1080×1080 | 여러 장 넘김용 |

**만드는 방법**

`<canvas>` 에 직접 그린다. 라이브러리 쓰지 말 것 —
⚠️ 이 저장소는 **빌드 단계가 없다.** npm 패키지를 넣으려면 구조를 바꿔야 한다.

- 폰트: `Apple SD Gothic Neo` / `Pretendard` (시스템). 웹폰트 링크 금지 — HANDOVER §5
- 색: 브랜드 시트 그대로 — `#0A0A0A`(먹) `#0A3D8F`(호라이즌 블루) `#E6E6E6`
- 로고: `prototype/logo-lockup.png` 를 오른쪽 아래에 작게
- 내려받기: `canvas.toBlob()` → `<a download>`.
  ⚠️ **Cesium 캔버스가 아니다.** 그쪽은 `preserveDrawingBuffer` 문제가 있다(§5)

**한 장에 들어갈 것** (카드뉴스 원고 참고)

```
┌─────────────────────────────┐
│ [작은 눈썹]  earthus         │
│                              │
│  큰 문장 한 줄                │
│  (숫자가 있으면 숫자를 크게)   │
│                              │
│  받침 문장 1~2줄              │
│                              │
│ ─────────────────────────    │
│ 출처 · 관측 시각        [로고] │
└─────────────────────────────┘
```

⚠️ **맨 아래 출처·시각 줄은 필수다.** 우리 화면의 좌하단과 같은 규칙이고,
이게 없으면 우리가 만든 카드가 아니다.

### 4-4. ③ 릴스 탭

**규격**: 1080×1920 세로, 10~20초

**만드는 방법 — 연속 캡처**

앱을 iframe 이 아니라 **새 창으로 열고** 정해진 장면을 밟으면서 프레임을 모은다.
`docs/talk/capture.md` 의 방법을 브라우저 안으로 옮긴 것이다.

⚠️ **cross-origin 이면 캔버스를 못 읽는다.** `studio.html` 과 앱이 같은
`earthus.net` 이라 문제없지만, 로컬에서 만들 때 포트가 다르면 막힌다 —
같은 포트에서 열 것.

**프레임 모으는 법 (검증된 방법)**

```js
// ⚠️ Cesium 은 preserveDrawingBuffer 가 꺼져 있어 toDataURL 이 빈 그림을 준다.
//    render() 직후 같은 태스크 안에서 읽어야 한다. (talk 자료 만들 때 실측)
viewer.scene.render();
const url = viewer.scene.canvas.toDataURL('image/png');
```

**장면 각본** (초안의 `kind` 에 따라 고른다)

| 장면 | 무엇 | 초 |
|---|---|---|
| 여는 장면 | 전지구 → 그 지역으로 날아감 | 2 |
| 본론 | 태풍 회전 / 구름 흐름 / 기관별 진로 겹침 | 6~10 |
| 자막 | 카드뉴스와 같은 문장 한 줄 | 계속 |
| 닫는 장면 | 로고 + `earthus.net/?tc=이름` | 2 |

⚠️ **나레이션·자막에 예보를 넣지 않는다.** 화면 원칙과 같은 원칙이다.
"태풍이 온다" 가 아니라 "네 기관이 이렇게 보고 있다".

**출력**: 우선 **프레임 PNG 묶음(zip 아님, 순번 파일 여러 장)** 으로 충분하다.
`MediaRecorder` 로 WebM 을 만드는 것은 2단계 — 브라우저마다 코덱이 달라
지금 붙이면 "왜 어떤 기기에선 안 되나"를 쫓게 된다.

## 5. 이미 밟은 함정 (다시 밟지 말 것)

| 함정 | 결과 | 규칙 |
|---|---|---|
| Cesium `toDataURL` | 빈 그림 | `scene.render()` 직후 같은 태스크에서 |
| 브라우저 다운로드 차단 | 파일이 안 떨어짐 | 사용자 클릭 안에서 `<a download>` 를 부를 것 |
| 웹폰트 링크 | 로딩 전에 그리면 글꼴이 틀림 | 시스템 폰트만. 그려도 `document.fonts.ready` 를 기다릴 것 |
| 무한 애니메이션 | 발열 | 캡처 중에만 돌리고 끝나면 멈춘다 (`power.animate`) |
| 손으로 만든 목록 | 실제와 어긋남 | 채널 목록·규격을 한 곳(상수)에 두고 거기서 읽을 것 |

## 6. 게시 — 「자동 배포」의 실제 모습

**허용되는 흐름**

```
초안 확인 → 카드/영상 생성 → 사람이 미리보기 확인
→ [올리기] 버튼 클릭 → 그때 비로소 채널로 전송
→ posted 에 기록
```

**절대 안 되는 흐름**: 시간이 되면 저절로, 새 초안이 생기면 저절로.

### 6-1. 1단계 — 지금 할 것 (승인 불필요)

플랫폼 API 승인은 시간이 걸린다. **먼저 이것부터 만든다**:

- 카드·영상 파일 **내려받기**
- 채널별 문구 **복사 버튼** (X / 스레드 / 인스타 각각)
- **`navigator.share()`** — 폰에서는 이거 하나로 인스타·스레드에 바로 넘어간다.
  ⚠️ 데스크톱 지원이 들쭉날쭉하다. 안 되면 내려받기로 떨어질 것

이것만으로 실제 운영이 된다. PD 가 폰에서 버튼 두 번 누르면 올라간다.

### 6-2. 2단계 — API 연동 (승인 후)

| 채널 | 방법 | 걸림돌 |
|---|---|---|
| X | API v2 · OAuth 2.0 | 무료 등급은 게시 횟수 제한이 있다. 확인 필요 |
| 스레드 | Threads API | Meta 앱 심사 |
| 인스타 | Graph API · 비즈니스 계정 필요 | 심사 + 계정 전환 |

⚠️ **토큰을 클라이언트에 두지 않는다.** Supabase Edge Function 으로 중계한다 —
`supabase/functions/checkout` 와 같은 구조다. `studio.html` 은 그 함수를 부르기만 한다.

⚠️ 각 채널 게시 후 `posted` 에 `{채널: {at, url}}` 을 기록한다.
중복 게시를 막는 유일한 방법이다.

#### 2026-08-10 구현 상태

- 관리자 메뉴의 `SNS 연동 설정`에서 X, Threads, Instagram, Facebook 자격증명을 입력한다.
- 원문은 브라우저 저장소에 두지 않고 `social-admin` Edge Function으로만 보낸다.
- Edge Function은 `SOCIAL_VAULT_KEY`로 AES-GCM 암호화한 파일만 비공개 Storage에 저장한다.
  설정 화면에는 필드 이름과 갱신 시각만 돌려주며 원문 조회 API는 없다.
- 서버 미디어 보관함은 최대 512MB의 사진·영상을 signed upload URL로 직접 올린다.
  출처와 관측·촬영 시각이 없으면 카탈로그에 등록하지 않는다.
- Meta가 미디어를 가져갈 때는 한시적 signed URL만 발급한다. 버킷 자체는 공개하지 않는다.
- 게시 요청은 화면의 최종 확인 체크와 브라우저 확인창을 모두 통과한 수동 POST만 허용한다.
- `provider + mediaId + text`로 중복 키를 만들고 서버 lock 파일로 같은 요청을 두 번 막는다.
- 성공 기록에는 채널, 게시물 ID·URL, 문구 SHA-256, 게시 시각, 관리자 UID만 남긴다.
  자격증명과 게시 문구 원문은 게시 이력에 남기지 않는다.
- 예약, cron, 초안 생성 이벤트에서 `social-admin`을 부르는 코드는 없다.

실제 X·Meta 앱의 토큰과 권한은 아직 입력하지 않았으므로 계정 확인과 실게시 검증은 남아 있다.

## 7. 잠금 (반드시 admin.html 과 같게)

```js
const known = ADMIN_UIDS.includes(user.id);   // ⚠️ length === 0 이면 통과 금지
```

⚠️⚠️ **목록이 비면 아무도 못 들어가는 것이 정상이다.** 예전에
`length === 0 || includes(...)` 로 써서 **비어 있으면 전원 통과**가 된 적이 있다.
`admin.html` 에서 그 코드를 그대로 복사할 것.

⚠️ `service_role` 키를 이 파일에 넣지 않는다. anon 키 + RLS 로만 접근한다.

## 8. 첫 30일 운영 계획 (화면이 지원해야 할 것)

카드뉴스 원고에 있는 계획이다. 화면은 이걸 편하게 만들어야 한다.

- 주 3회 릴스 — 태풍·구름·위성 궤도 중 **그날 실제로 볼 만한 것**
- 주 2회 카드뉴스 — 발표자료 3부의 사례를 하나씩 푼다
- 특보가 뜬 날은 그날 화면을 그대로 올린다 (만들 필요가 없다)

→ 그래서 **「지금 화면 그대로 카드로」** 버튼이 실제로 제일 많이 쓰일 것이다.
초안이 없어도 만들 수 있어야 한다.

## 9. 완료 조건

2026-08-05 로컬 검증: 390×844와 데스크톱에서 카드 3규격, IndexedDB
보관함, Cesium 단일·8장 연속 프레임을 실제 생성했다. 운영 데이터 구조도
`social-drafts.json`과 대조했다. 아래의 계정·공유창·배포 항목은 운영 환경에서
다시 확인해야 한다.

- [ ] `studio.html` 이 관리자 UID 로만 열린다 (다른 계정·비로그인은 막힘)
- [ ] 초안 목록이 뜨고 `facts` 를 펼쳐 볼 수 있다
- [x] 카드 3규격이 PNG 로 떨어지고 **출처·시각 줄이 들어 있다**
- [x] 릴스 프레임이 1080×1920 으로 떨어진다 (Cesium 캔버스가 검게 나오지 않음)
- [ ] 문구 복사 버튼이 채널별로 동작
- [ ] `navigator.share()` 가 되는 기기에서는 공유창이 열린다
- [x] **자동 게시 경로가 코드 어디에도 없다** — 타이머·cron·이벤트로 게시하는 코드 금지
- [x] SNS 자격증명은 클라이언트 저장 없이 서버에서 암호화한다
