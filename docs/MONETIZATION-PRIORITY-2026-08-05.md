## 2. 핵심 판단

공공 API의 현재값을 보기 좋게 다시 보여주는 것만으로는 구독 이유가 약하다.
earthus가 팔 수 있는 고유 자산은 **그 시각에 기관과 모델이 무엇을 예보했는지 붙잡아 둔 기록**이다.
관측은 나중에도 다시 받을 수 있지만, 갱신되어 사라진 예보는 소급 복원이 불가능하다.

새 상품 구현 전에 이미 적어 둔 약속부터 실제 상태와 맞춘다.

1. **구독 화면 진실성** — 미완성 기능은 `준비 중`, 무료 기능은 유료 목록에서 제거
2. **Personal Pro 가격 정합성** — 화면과 서버 정본을 월 ₩5,900·연 ₩49,000으로 통일
3. **마케팅 스튜디오** — 자동 게시 없이 사람이 검수할 초안을 만드는 현재 제품 작업

그 뒤 유료 상품 구현 순서는 다음과 같다.

1. **예보 검증** — 첫 유료 상품 후보
2. **관측소 입양** — 30일 이력이 실제로 쌓인 뒤
3. **Research Pack·교육 상품** — 앞의 두 상품이 동작한 뒤
4. **Field Pass·제휴 링크** — 현재 하지 않음

계획을 더 추가한다는 이유로 위 순서를 다시 바꾸거나 마케팅 작업을 뒤로 미루지 않는다.

## 3. 가격 정본

현재 판매 후보는 Personal Pro 한 종류다. 월간과 연간은 권한 차이가 아니라 이용 기간만 다르다.

| 이용권 | 한국 | 해외 표시 | 자동 갱신 |
|---|---:|---:|---|
| 1개월 | ₩5,900 | $4.99 | 웹 카드 결제는 없음 |
| 1년 | ₩49,000 | $39 | 웹 카드 결제는 없음 |

- 화면 표시: `prototype/js/billing.js`의 `DEFAULT_PLANS`
- 실제 청구 정본: Supabase `plans` 표와 재실행용 `prototype/supabase/billing.sql`
- 저장소의 재실행용 SQL은 이 가격으로 맞췄다. 판매를 열기 전 라이브 `plans` 표에도
  같은 SQL을 적용하고 checkout 응답 금액을 대조한다.
- 할인율은 화면 언어의 통화로 계산한다. KRW 할인율을 USD 화면에 재사용하지 않는다.
- 실제로 받은 적 없는 가격을 취소선 정가로 쓰지 않는다.
- 창립회원 연 ₩19,000 상품은 되살리지 않는다. 창립 멤버 표시는 가격과 별개다.
- `SALES_OPEN=false`는 가격 결정과 무관하게 아래 판매 조건을 모두 통과할 때까지 유지한다.

## 4. 1순위 — 예보 검증

### 팔 수 있는 것

- 선택한 지점·시각·선행시간에서 각 기관·모델이 발표한 값
- 같은 시각의 실제 관측값
- 두 값의 차이와 계산 방법
- 발표시각·유효시각·관측시각·출처·격자 해상도·표본 수 `n`
- earthus가 그 예보를 처음 보관한 시점부터의 되감기

10일치만 있어도 개별 사례는 보여줄 수 있다. 다만 표본이 적은 상태에서 장기 성능을
대표하는 순위·우승자·정확도 등급을 만들면 안 된다.

### 표현 원칙

`KMA가 JMA보다 나쁘다`, `가장 정확한 기관`처럼 earthus가 기관을 판정하는 문구를 쓰지 않는다.
다음 사실까지만 보여주고 판단은 사용자에게 맡긴다.

> 8월 4일 12시 서울의 24시간 전 예보
> 기상청 31°C · ECMWF IFS 29°C · GFS 30°C
> 같은 시각 서울 관측 30.4°C · 각 자료의 발표·관측시각과 출처 표시

기관 자료와의 관계, 표본 편향, 결측, 지점 관측과 모델 격자의 차이를 방법론 화면에 항상 둔다.
집계값을 추가할 때도 선행시간·지역·변수를 섞지 않고 `n`과 기간을 함께 표시한다.

## 5. 2순위 — 관측소 입양

현재값·24시간 스파크라인·최고/최저가 발생한 시각·풍향 장미 같은 기본 대시보드는
먼저 만들 수 있다. 그러나 유료 후크인 `지난 30일`과 `작년 같은 날`은 실제 이력이 있어야 한다.

- `지난 30일`: 2026-07-27부터 30일이 쌓이는 **2026년 8월 말부터** 제공
- `작년 같은 날`: 1년 전 같은 날짜가 생기는 **2027년 7월부터** 제공
- 그 전에는 준비 중인 기간을 정확히 표시하고 결제를 받지 않음
- 무료 1곳 / 유료 20곳 구조는 유지하되, 알림이 실제 전달되는지 검증하기 전에는 알림을 판매하지 않음

## 6. 에코뱅크 이용조건 — 상품 3·4의 관문

현재 자료는 eBird나 Movebank가 아니라 **국립생태원 에코뱅크 자료**다.
기존 문서의 eBird·Movebank 경고만으로 에코뱅크의 상업 이용 가능 여부를 대신할 수 없다.

공공데이터포털의 자연환경·생태계정밀·백두대간정밀조사 조류 점 API 3종은
공공누리 제1유형이다. 출처를 밝히면 상업 이용과 가공이 가능하다. 그러나 같은
표시에 **제3자 권리 포함**이 명시돼 있고, 에코뱅크 저작권 정책도 국립생태원이
권리 전부를 보유하지 않은 자료를 별도로 경고한다.

따라서 무료 5km 집계 지도는 출처·제1유형·제3자 권리 경고를 함께 표시해 유지하고,
에코뱅크 자료를 쓴 유료 Research Pack·교육 상품·CSV·API는 권리 범위를 서면으로
확인할 때까지 열지 않는다. 상세 근거와 문의 질문은
[`ECObank-LICENSE-2026-08-06.md`](ECObank-LICENSE-2026-08-06.md)에 기록했다.

- 상업 이용 및 유료 서비스 포함 허용 여부
- 원자료 재배포와 가공·통계 결과 제공의 구분
- 출처·라이선스 표기 문구
- 다운로드·캐시·장기 보관 허용 범위
- 제3자 제공·CSV·API 내보내기 허용 범위

확인 전 상태는 `금지`가 아니라 **미확인으로 인한 보류**다. 허용된다고 추정하지 않는다.

## 7. 제휴 링크 결정

Field Pass를 포함한 신규 제휴 링크 상품은 현재 추진하지 않는다.

earthus의 유료 명분은 `이 값을 믿을 수 있는가`인데, 추천 결과에 수수료가 연결되면
자료 선택과 배열의 독립성을 계속 증명해야 한다. 초기 매출 기여보다 신뢰 비용이 크다.
기존 코드의 제휴 연결 지점도 활성화하지 않는다. 앞의 두 직접 상품이 동작한 뒤 별도 판단한다.

## 10. 2026-08-06 실행 기록

- 실제 2일 이상일 때만 Custom Extract manifest와 인용 메모에 `daily-trend`
  CSV의 파일명·행 수·BOM 포함 바이트·SHA-256·열 정의·누락 날짜 비보간 방법을
  추가한다. 1일 범위에는 존재하지 않는 추세 파생물을 기록하지 않는다.
- 예보·관측 사례 선택 범위를 날짜×모델×선행시간×변수별 n·ME·MAE·RMSE로 다시
  집계해 추세 CSV와 SVG를 만든다. 실제 날짜 2일 이상에서만 활성화하고, 빠진 날짜
  사이를 선으로 연결하지 않으며 각 점의 n·출처 파일 수·단기 범위 경고를 남긴다.
- Custom Extract를 실제 공개 인덱스의 시작일–종료일 범위로 확장했다. 범위 안 실제
  포함 날짜와 달력상 누락 날짜, 날짜별 원본 파일 경로·출처·이용조건·생성시각을
  `earthus.custom-extract-manifest.v2`에 기록한다. 등록된 파일 하나라도 로드에 실패하면
  부분 추출을 만들지 않는다.
- Custom Extract manifest의 `derivedFiles`에 선택 범위 품질 CSV의 파일명·행 수·
  BOM 포함 바이트·SHA-256·열 정의·계산 설명을 연결하고, 인용·방법 메모에도 같은
  체크섬을 기록한다.
- Custom Extract 선택 범위에서 사례는 모델×선행시간×변수별 유효 표본·결측과
  ME·MAE·RMSE를, ASOS는 변수별 관측/숫자/결측 표본·결측률·최솟값·최댓값·평균을
  계산해 화면과 CSV로 제공한다. 문자열 관측은 numeric_n과 분리하고, 같은 날짜 밖의
  값을 섞거나 장기 순위를 만들지 않는다.
- Custom Extract의 CSV·manifest와 함께 보관할 인용·방법 Markdown 메모를 추가했다.
  같은 manifest의 파일명·행 수·바이트·SHA-256, 선택 조건, 원본 URL·출처·이용조건·
  생성시각·방법론을 옮기고, 임의 DOI가 아닌 작업 메모임을 명시한다.
- Custom Extract의 현재 선택 CSV와 정확히 대응하는
  `earthus.custom-extract-manifest.v2` JSON을 제공한다. CSV 파일명·행 수·BOM 포함
  바이트·SHA-256, 필터·열 정의·원본 경로·출처·이용조건·생성시각·방법론을 기록한다.
- Research Custom Extract는 실제 공개 인덱스에 있는 날짜와 그 일파일만 읽는다.
  예보·관측 사례와 ASOS 시간 관측을 시각·관측소·변수로 걸러 long format CSV로
  내보내며, 각 행에 좌표·단위·출처·이용조건·생성시각을 남긴다. 결측은 빈칸으로
  유지하고 예보−관측 차이는 소수 셋째 자리까지 정리한다.
- Research Figure Builder에서 실제 일별 집계의 날짜·기온/풍속·MAE/ME/RMSE를 골라
  모델×24/48시간 값을 SVG로 내보낼 수 있게 했다. 그림 파일 자체에 기간·단위·각 막대의
  표본 수 `n`·출처·생성시각을 남기고, 한 날 표본은 장기 성능 순위가 아니라는 경고를
  포함한다. ME의 음수 막대는 0 기준선 아래에 그린다.
- Research Pack CSV 3종의 정렬 순서를 고정하고, 각 파일의 행 수·바이트·SHA-256,
  40개 열의 이름·단위·설명, 출처 경로·생성시각·범위, 결측·오차·선행시간 방법론을
  `earthus.research-manifest.v1` JSON으로 내려받게 했다. 일사 원본값은 단위를 확인하지 못해
  임의 단위를 쓰지 않고 `원본 단위 미표기`로 보류했다.
- `research.html`에서 실제 사례의 유효시각·ASOS 관측소·기온/풍속을 고르면 GFS·ECMWF
  24/48시간 예보, 관측, 차이, 발표시각, 출처, `n`이 든 1장 활동지를 만들고
  인쇄·PDF 저장할 수 있게 했다. 한 사례로 모델 우열을 판정하는 문구는 넣지 않았다.
- `verify.html`에 일별 MAE·ME·RMSE·`n`과 별도로 지점·시각별 예보·관측 사례를 공개했다.
- 사례 원본은 `archive/verify/fc/`를 직접 열지 않고, 관측과 짝이 맞은 변수만
  `wind/series/verify-cases/<날짜>.json`으로 분리한다.
- KMA 관측은 보통 한 시간 늦게 들어온다. 선행 24·48시간 파일은 Lambda 실행 시각이 아니라
  **관측 시각에서 24·48시간을 뺀 시각**으로 고른다.
- 기존 11일 일별 집계에는 실제 23·47시간 파일이 24·48시간으로 표시된 한 시간 오차가
  섞였을 가능성이 있어 판매·비교에 사용하지 않는다. 비공개 사고 보관본으로 옮기고
  `leadBasis=observation-time` 기준으로 2026-08-06부터 다시 적재한다.
- 지점별 공개 사례는 2026-08-06부터 쌓인다. 소급 생성 전에는 그보다 긴 사례 기간을 약속하지 않는다.
- `station.html` 무료 MVP는 ASOS 한 지점을 브라우저 기기에 저장하고 현재 관측과 실제
  날짜별 관측 이력에 쌓인 기온·풍속만 보여준다. 관측 이력은 예보 검증 파일과
  독립적으로 `kma-aws`가 매시 적재한다. 30일은 빠르면 2026-09-05, 작년 같은 날은
  빠르면 2027-08-06 이후 실제 보유 여부를 확인한 뒤 연다.
- `research.html`은 최신 공개 범위만 일별 검증·ASOS 시간 관측·지점 사례 CSV로
  변환하고 데이터 사전과 수업 질문을 제공한다. 장기 자료가 있는 것처럼 쓰지 않으며 판매는 잠근다.
