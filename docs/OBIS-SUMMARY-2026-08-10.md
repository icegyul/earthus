# OBIS 5도 해역 요약 — 2026-08-10

## 무엇을 만들었나

잠수 화면에서 선택 좌표가 속한 5°×5° 해역의 OBIS 관측 기록 수, 종 수준 분류 수,
자료묶음 수, 기록 연도, 상위 학명 5개를 보여 준다. 원자료를 실시간으로 부르지 않고
`obis-summary` Lambda가 S3 `ocean/obis-summary.json`에 미리 굽는다.

첫 배포 범위는 해구 교육 카드 10곳과 한국 주변 바다 3곳이 속한 13개 셀이다.
포함되지 않은 셀은 0건으로 표시하지 않고 “이번 요약 대상에 아직 포함되지 않았다”고
쓴다. 모든 화면에 `기록 없음 ≠ 생물 없음`과 조사 노력의 불균등, 개체수·현재 분포가
아니라는 한계를 고정했다.

## API 스파이크

2026-08-09 14:58 UTC 무렵 OBIS API v3의 `statistics`와 `facet`을 5도 WKT 해역
3곳에서 실측했다.

| 해역 | statistics | facet(scientificName) |
|---|---:|---:|
| 한국 주변 125–130°E, 33–38°N | 106B · 2.13s | 467B · 2.91s |
| 마리아나 주변 140–145°E, 9–14°N | 105B · 1.71s | 491B · 1.15s |
| 남태평양 −135–−130°E, −40–−35°N | 97B · 1.30s | 438B · 2.44s |

응답은 작지만 한 요청이 1–3초 걸린다. 전 세계 2,592개 셀을 매주 두 번씩 호출하면
공공 API에 불필요한 부하를 준다. 그래서 교육 화면에서 실제로 연결하는 13개 셀만
순차 호출하고 셀 사이 0.25초를 둔다. 브라우저 런타임의 OBIS 직접 호출은 없다.

## 첫 운영 산출물

- Lambda 실행: 13셀 갱신, 실패 0, JSON 8,470B
- 챌린저 해연 셀(10–15°N, 140–145°E): 기록 123,633건, 종 수준 분류 3,781종,
  자료묶음 103개, 기록 연도 1849–2026
- 스키마: `earthus.obis-summary.v1`
- 자동 실행: EventBridge `cron(30 18 ? * SUN *)` — 매주 월요일 03:30 KST
- 원천: OBIS API v3, Ocean Biodiversity Information System, IOC-UNESCO

상위 목록은 `scientificName` facet의 기록 수 순서다. 종뿐 아니라 속·과·상위 분류군이
섞일 수 있으므로 화면에서 “상위 종”이라 부르지 않고 “상위 학명” 목록으로만 보여 준다.

## 이용 조건과 한계

OBIS는 원 자료묶음별 라이선스를 확인하고 원 제공자와 OBIS를 인용하도록 요구한다.
이 기능은 원행을 재배포하지 않고 집계 정보 제품만 제공하지만, 화면에 OBIS 출처와
자료 정책 링크를 항상 둔다.

- API: https://api.obis.org/
- 자료 정책: https://manual.obis.org/policy.html
- 인용 안내: https://manual.obis.org/citing.html

OBIS 자체도 공간·시기·조사 방법이 고르지 않고 분류·위치 오류 가능성이 있음을
경고한다. 따라서 이 요약으로 생물이 없다고 판정하거나, 현재 개체수·분포를 말하거나,
해역 간 풍부도를 단순 비교하지 않는다.
