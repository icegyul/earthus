## 1. 즉시 조치 — 유료 상품이 버그로 죽어 있다

`ocean/cyclone-reports.json` **22개 보고서 전부 `scores` 0건**. 유료회원에게 보여줄 "기관별 평균 위치오차"가 한 건도 없다.

원인은 [aws/cyclone-analog/handler.py:148](aws/cyclone-analog/handler.py) `iso_time()`:

```python
parsed = datetime.fromisoformat(text.replace("Z", "+00:00"))
if parsed.tzinfo is not None:          # ← 시간대 없는 값은 여기서 버려진다
    return parsed.astimezone(timezone.utc)
```

재현:

| 입력 | 결과 |
|---|---|
| `'2026-08-15 06'` | **None** ← IBTrACS 점 시각 |
| `'2026-08-15 06:00'` | **None** |
| `'202608150600'` | ✅ 파싱됨 |
| `'2026-08-15T06:00:00Z'` | ✅ 파싱됨 |

CWA(+08:00) 시각을 UTC로 **추측하지 않으려던 의도**가 IBTrACS의 시간대 없는 시각까지 같이 버리고 있다. 자료원별로 갈라야 한다 — CWA만 None으로 남기고, IBTrACS·GTS처럼 UTC가 규약인 자료원은 naive 값을 UTC로 읽어야 한다.

### 공통 차단 사유 (검증 HIGH로 확인됨)

1. **유료 등급 기능이 거의 전부 `soon`** — INTELLIGENCE 10항목 전부, EXPLORER 11항목 중 8개.
2. **기상청 동네예보 회차가 한 건도 보관되지 않는다.** `kma-fcst`는 단일본을 덮어쓴다. 채점 대상은 Open-Meteo 경유 **GFS·ECMWF-IFS 2모델 × 기온·풍속 2변수 × 24/48h 2선행**뿐 — 기상청·JMA·AIFS·강수·기압이 채점에 없다.
3. **검증 예보 축의 원천이 Open-Meteo 무료 API(비상업 전용)** — 검증 기록을 유료로 파는 것 자체가 약관상 잠겨 있다.
4. **DOI·영구 URL·버전 식별자 없음** — 논문 참고문헌에 넣을 수 없다. 연구 추출 README가 스스로 "공식 DOI가 아닙니다"라고 적는다.
5. `provenance.html`이 운영 사이트에서 **403** — 기사 각주에 붙일 permalink 요건 미달.

### 반박된 것 — 우리가 스스로 과대평가하던 지점

| 우리 가정 | 반박 (HIGH) |
|---|---|
| "ECMWF는 2~3일만 보관하니 우리 아카이브만 유일한 소급 불가 자산" | **거짓.** ECMWF가 직접 관리하는 AWS Open Data 버킷 `s3://ecmwf-forecasts`에 CC-BY-4.0으로 남아 있다 |
| "예보 검증 기록은 우리만 갖고 있다" | **Open-Meteo Previous Runs API**가 무료·CC-BY로 같은 것을 더 넓게 준다 (서울 좌표로 실측 확인) |
| "산악예보 gap 일별 기록이 고유 자산" | 입력 둘 다 페르소나가 이미 키를 가진 무료 API |
| "이안류 알림 20곳이 유료 가치" | KHOA **'안전해' 앱이 같은 10곳을 무료로** 알림 제공 |
| "해양 자료 전부 Open-Meteo 경유라 판매 불가" | 거짓 — KMA 부이 **실측**은 별개 경로. 단 부이-모델 대조 기능은 실제로 없음 |

## 3. 전문가 5인이 원한 것은 하나로 수렴한다

분야가 전부 다른데 **같은 물건**을 요구했다:

| 전문가 | 요구 |
|---|---|
| 예보 검증 전문가 | 97 ASOS 다기관·다모델 검증 원행 CSV (station·source·run_utc·lead_h·valid_utc·fc·obs·diff·license) |
| 연구자 | ECMWF IFS vs AIFS 한국 ASOS 검증 데이터셋 + SHA-256 manifest + CITATION.cff |
| 해양 실무자 | 한국 해상 파고 예보 검증 일보 CSV (부이 실측 × 모델 × 선행시간) |
| 저널리스트 | 사건별 예보-실제 대조 팩 CSV |
| 방재 담당자 | 특보구역별 재해 사건 대장 CSV |

**공통 골격: `그때 무엇을 예보했고 실제로 무엇이 왔는가`를 행 단위 CSV로 + 출처·라이선스·SHA-256.**

이것은 `MONETIZATION-PRIORITY-2026-08-05.md` §2가 이미 "팔 수 있는 고유 자산"이라고 지목한 바로 그것이다.

### 지금 자원으로 얼마나 되나 — 70%

**있는 것**
- `archive/ecmwf/<run>.json` IFS·AIFS 97지점 회차 보관 (2026-08-01~, CC-BY-4.0 **권리 깨끗**)
- ASOS 시간 관측 이력 `wind/series/stations/` **760일 보존**
- 채점 뼈대 `aws/kma-verify` `score()` — 관측시각 기준 lead·결측 제외·n≥20·ME/MAE/RMSE
- 감률 보정 `aws/mountain-verify` 5.5°C/km
- CSV + SHA-256 manifest + verify.py 생성기 `prototype/js/research.js`
- **GRIB2 직접 해독 실증** `aws/tpw-grid` (NOMADS grib filter) ← Open-Meteo 탈피 경로

**없는 것**
- 기상청 동네예보 **회차 스냅샷** (단일본 덮어쓰기 중 — put 경로 한 줄 추가 수준)
- 파고 예보 회차 수집 (ecmwf-ingest는 `PARAMS=['2t']` 육상 97지점뿐)
- DOI·영구 URL·CITATION.cff
- 통계층 (skill score·Diebold–Mariano·고도 보정 ±250m 제외)

## 5. 순서

1. **`iso_time()` 버그 수정** — 유일한 유료 상품 22건을 살린다. 반나절.
2. **`kma-fcst` 회차 스냅샷 저장** — put 경로 한 줄. 이게 없으면 "기상청 예보가 맞았나"를 영원히 못 판다.
3. **ECMWF IFS vs AIFS 검증 CSV** — 권리 깨끗한 자산(CC-BY-4.0)으로 만드는 첫 상품. 전문가 5인 중 3인이 이걸 요구했다.
4. **Open-Meteo → 원천 GRIB 이전** — `tpw-grid`가 이미 경로를 증명했다. 상업 판매의 전제.
5. 가격은 그 다음. **지금은 무엇을 파는지가 없어서 가격이 무의미하다.**
