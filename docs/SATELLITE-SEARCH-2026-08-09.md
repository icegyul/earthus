# 위성 별칭 검색 실행 기록

작성 2026-08-09 · 무료 교육 퀵윈

## 구현 범위

- 검색창이 장소·레이어·위성을 함께 찾는다. placeholder와 빈 화면 안내도 ko·en으로
  위성을 포함하도록 바꿨다.
- `sat-aliases.json` 첫 8기: 천리안2A, 국제우주정거장, 허블, 아리랑 2·3·5·3A·7호.
- 별칭은 운영 `celestrak/catalog.json.gz`의 CelesTrak OMM JSON + SATCAT JSON
  카탈로그(생성 `2026-08-08T18:01:01.070Z`)와 이름·NORAD 번호를 대조했다.
  기억이나 블로그 번호를 쓰지 않았다.
- 검색 결과를 누르면 필요한 위성 그룹을 켜고 자료 수신 상태를 표시한 뒤, SGP4로
  클릭 시각의 위치를 한 번 계산해 이동하고 기존 위성 상세 시트를 연다.
- 검색으로 지정한 한 기가 기기별 렌더 상한에 잘리지 않게 앞으로 옮기되, 전체 렌더
  상한은 늘리지 않는다.
- 상세 시트에 계산 위치, 계산 시각, `CelesTrak OMM · SGP4` 방법을 추가했다.

## 검증

- `tools/validate_catalogs.py`: 8개 별칭의 NORAD 숫자, ko/en 배열, 실제 그룹,
  종류 ko/en, 카탈로그 출처·관측 시각 통과.
- JS 문법 검사와 `git diff --check` 통과.
- 새 localhost 저장공간에서 위성 레이어가 꺼진 상태로 `천리안` 검색 → 위성 결과 선택 →
  로딩 문구 → `GEO-KOMPSAT-2A` 상세 시트까지 통과.
- 실측 계산 위치는 `0.01°N · 128.28°E`, 고도 `35,792 km`, 계산 시각과 방법이
  상세 시트에 함께 표시됐다. 사양 완료 조건의 동경 128.2° 부근과 일치한다.
- 운영 영문 화면에서도 `GEO-KOMPSAT-2A` 검색 결과와 `Calculated position`,
  `Position calculated`, `Position source & method` 상세를 확인했다.
- 운영 6파일 SHA-256이 로컬과 일치했다. CloudFront 무효화:
  `ICE0908DM6V2R46CPKUA711U7Q`.

## 아직 확장할 것

- 천리안2B·무궁화는 현재 우리가 무료 기본 그룹으로 받는 카탈로그 묶음에 없다.
  `all` 그룹을 강제로 받으면 대역폭·발열 원칙을 깨므로 넣지 않았다. 별도 GEO 소형
  수집 경로를 만들 때 추가한다.
- 별칭은 8기부터 배포한다. 아리랑 후속기·무궁화 등 약 30기 목표는 같은 검증을 거쳐
  점진적으로 늘린다.
