## 0. 한 줄 결론

**폰 아래를 "시트 하나 + 타임라인 하나" 두 자리로 줄인다.** 알약(탐색 5칸)은 시트의 맨 아래 줄로 붙이고, 좌하단 출처 상자는 없애는 대신 **출처·시각을 타임라인 아래 두 줄에 넣어 늘 보이게** 한다. 손잡이는 본문 밖으로 빼서 표적 44·스크롤해도 남게 한다.
아래 자리(알약 윗변~바닥): 212px → **140px** [실측 402×714]. 창 수: 3(알약·출처 상자·타임스트립) → **1(타임라인)** + 필요할 때 시트.

왜 지금 사슬을 다시 세워야 하나 — 한 가지 증거: 토큰 `--hud-h: 79px`("2줄일 때의 높이 (실측)")은 **이미 틀려 있다.** 360 폭 영어에서 #hud 는 89px 이고 알약과 3px 떨어져 있다(세 제안 중 두 곳이 따로 잼). 부품마다 남의 bottom 을 피해 가며 숫자를 박은 결과다. 자리의 주인이 없다(메모 2026-09-23 PD).

## 2. 각 요소가 어디로 가는가

① **타임라인 #timestrip — 하나뿐인 아래 막대(정본 '하단 Global Timeline 하나').**
- 맨 아래 bottom 8+안전영역, 높이 72, 폭 386(지금 max-width 378 → none).
- 1줄: 지금·▶·슬라이더·NOW. 44px 표적 규칙(::after, 음수 바깥여백)은 **한 글자도 안 바꾼다**(phone-reach ㉢ 그대로).
- 2~3줄(각 13px, 10px 글씨): **출처·시각 칩.** 누를 수 없는 글씨(pointer-events:none) + 오른쪽 끝 ▾ 하나.
  - 첫 줄 = 바뀌는 출처와 **관측·런 시각** — 예 `관측 구름 NOAA GMGSI 09-23 10:00Z · 입체는 추정(DERIVED) · 운정고도 KMA L2 10:20Z`
  - 둘째 줄 = **표기 의무 크레딧(자르지 않는 줄)** — `AWS Terrarium · Natural Earth II · 과장 50×` ▾
  - 실측: 402 한국어, 360 영어 모두 첫 줄에 기관·시각이 다 보였다. 넘치는 뒤꼬리(운정고도 등)만 … 로 잘린다.
  - ⚠️ 1줄 칩(정본안 원안)은 **402 에서도 시각이 잘렸다**(`관측 구름 NOAA GMGSI 1…` 실측). '모든 값에 출처와 시각'을 어긴다 → 2줄로 올렸다. 대가 14px.
- 칩을 타임라인 안에 두는 이유: 시트가 닫혀도, 서랍이 열려도 늘 남는 부품은 타임라인뿐이다. 정본 W5 "모델·런 시각은 타임라인 옆에 항상"과 같은 자리다.

② **알약 #bottom-nav — 시트의 맨 아래 줄.**
- `left 8 · width calc(100vw − 16px − 좌우 안전영역) · bottom var(--ts-reserve)`. ⚠️ **`right` 를 쓰지 않는다** — phone-reach ㉤ 의 `landOn`(497행)이 `#bottom-nav` 에 right 가 있으면 가로 화면으로 판정한다.
- 5칸 flex:1(≈75×44), 라벨 11px. v1 #menuMain(390×62, 칸 55×52)과 같은 '전폭 바닥 줄' 모양 — PD "v1 메뉴 사이즈가 좋아"의 **모양**만 빌린다.
- 시트가 열리면 시트 아랫변(bottom var(--nav-reserve))과 맞붙어 한 장으로 보인다(맞닿는 모서리 각지게, 배경 .97). DOM 은 옮기지 않는다 — CSS 토큰으로만 붙인다.
- NAV_ITEMS·id·data-nav·두 번 누르면 닫힘: 그대로. 2026-09-09 '알약 숨김 금지' 기록은 더 강하게 지켜진다(모든 시트 단계에서 보인다).

③ **출처 상자 #hud — 평소 숨기고, ▾ 로 펼친다.** 지우지 않는다.
- 폰 세로: `#hud:not(.open) { display:none }` (hidden 속성 금지 — 다른 코드가 상자를 읽는다). DOM·id·#hud-line·#srcNote·#hud-detail 은 그대로 둔다.
- 칩의 ▾ → `#hud.open` → 타임라인 바로 위에 **출처 전문 + 고도 + 진단 복사**를 펼친다(지금의 ▾ 펼침과 같은 내용). 새 카드·새 창을 만들지 않는다.
- ▾ 이름을 '진단 정보' → '출처 전체 · 진단 정보' / 'Full sources · diagnostics' 로(i18n.js hudMore, 최소위험안에서 접목).
- main.js paintSrc: #srcNote 는 원문 그대로 쓰고, 같은 함수가 칩에 **짧은 판**을 함께 쓴다. 짧은 판은 기관명·시각을 앞에, 설명 문구는 ▾ 쪽으로.
  - ⚠️ 짧은 판에서도 **DERIVED/OBSERVED 진리등급은 줄이지 않는다**. 문구는 PD 승인본을 쓴다(아래 질문 1).
- ⚠️ #hud-line 을 쓰는 하위 뷰 5곳(main.js 지도·SolarView·SkyView·GalaxyView·LocalTerrain, 2427–2441행 근처)의 모드 글자: **하위 뷰가 켜진 동안에는 #hud 를 숨기지 않는다**(그 화면들은 지구 타임라인의 뷰가 아니다). 각 뷰의 body 표지를 구현 1단계에서 확인한다 — 확인 전에는 [추정].

④ **시트 #intel — 시트 하나.** left 8 · 폭 386 · bottom var(--nav-reserve)=140.
- half 31dvh → **28dvh**(손잡이 24 가 본문 밖으로 나가므로 내용 높이는 176 ≈ 오늘 179).
- peek 118 그대로(손잡이가 빠져 내용이 30px 늘어난다).
- full 천장 = `--top-reserve` 108 (범례 윗변과 같은 값). 오늘 full 이 도구줄을 14px 덮던 겹침이 사라진다(최소위험안에서 접목).

⑤ **탐색 서랍 #menu-panel** — 식은 그대로. reserve 가 줄어 저절로 내려온다. 서랍을 v1 크기(55%→39%)·한 탭으로 줄이는 일은 **별건**이다(메모 'v2 폰 창 줄이기', 이 제안 범위 밖).

⑥ **#quake-cap** — `bottom: 148px` 박힌 수 두 곳 → `calc(var(--nav-reserve) + 8px)`.

⑦ **바꾸지 않는 것** — 위쪽(전환기·도구줄·범례·브랜드 손잡이), 가로 폰(812×375·667×375 는 오늘 토큰 그대로), 데스크톱, `#map-attrib`(Esri · Maxar · Earthstar, 2D 지도 화면), AETHERUS 사진관의 ESO·NASA 크레딧 — 이 제안 밖이고 그대로 보인다.

### 자리표(토큰) — 숫자는 :root 한 곳에만

세로 폰 전용 `@media (max-width:720px) and (orientation:portrait)` 안의 :root:

```
--ts-h:       72px   /* 타임라인: 조작 1줄 + 출처·시각 2줄 */
--ts-gap:     6px    /* 유일한 조절 손잡이(최소위험안의 --dock-gap) */
--ts-reserve: calc(8px + var(--ts-h) + var(--ts-gap) + env(safe-area-inset-bottom))   /* = 86 */
--nav-reserve: calc(var(--ts-reserve) + var(--nav-h))                                /* = 140 */
--grip-h:     24px   /* 보이는 손잡이 띠. 표적은 44 */
--top-reserve: 108px /* full 시트 천장 = 범례 윗변 */
```

사슬은 이 셋으로 끝난다: 타임라인 → 알약(`--ts-reserve`) → 시트·서랍(`--nav-reserve`). `--nav-lift`·`--hud-lift`·`--hud-h` 는 세로에서 더 안 읽는다(가로 블록은 그대로 읽는다).

## 3. B4 — 시트 손잡이

**결론: 본문 밖으로 뺀다. 보이는 띠 24, 누르는 표적 44, 스크롤해도 남는다.**

- ui-shell.js 의 `<button class="sheet-grip">` 을 `#intel-body` 안에서 **#intel 의 첫 자식**으로 옮긴다(템플릿 한 줄).
- 띠 24px(배경 .97, 위 모서리 12), 막대 42×4 가운데. `::before` 로 위 8(지구 쪽)·아래 12(본문 윗여백, 누를 것 없음)를 넓혀 386×44.
- 닫힌 시트: `#intel:not(.open) .sheet-grip { display:none }`.
- 누르기(한 단씩)·끌기(|dy|≥24)·롱프레스 없음 — 코드 그대로(m1 시험).
- 글자 규약: M1 절 뒤 `.sheet-grip { display: block;` … `touch-action: none` 를 그대로 둔다(m1-bottom-sheet 34·35행이 이 글자를 읽는다). 넓은 화면 `.sheet-grip { display: none; }` 그대로.
- ✕ 는 탭 줄에 그대로(3열 탭 격자 사고 기록 유지).

| 단계 | 오늘 | 추천안 |

| peek | 118 = 손잡이 30 + ✕ 줄 30 + 내용 58 | 손잡이 24 + 본문 118(✕ 줄 30 + 내용 88) |

## 4. 지구가 보이는 비율

같은 잣대로만 견준다. **두 잣대를 다 적는다.**
- **(가) 누를 수 있는 지구** = 화면 14px 격자에서 elementFromPoint 가 캔버스인 비율(ux-check 와 같은 방식). pointer-events:none 인 범례·글씨는 '지구'로 센다.
- **(나) 상자 없는 지구** = fixed 상자에 안 가린 비율. 글씨·범례도 '가림'으로 센다. **눈에 보이는 것에 더 가깝다.**

## 7. 대안 2개와 버린 이유

| | 합치기안 (P1) | **추천안 (P2 정본안 + 접목)** | 최소위험안 (P3) |
|---|---|---|---|
| 모양 | 판 하나에 [출처 자막 3줄 54] + [타임라인 44] + [탐색 54] | [시트 + 알약 맨 아래 줄] + [타임라인 72, 출처 2줄 포함] | 순서·DOM 그대로, 자리표 토큰 + 출처 상자 56 고정 |
| 아래 기물(402) | 152+8 = 160 | **140** | 172 |
| 지구 (가)/(나) 평상시·half·지점 [402] | 77/74 · 52/48 · 52/37 | **75/75 · 50/51 · 50/40** | 73/– · 49/– · 48/– |
| half 전폭 띠 | 222 | **248** | 203 |
| 창 수 | 1(판) + 반투명 자막 | 1 | 3 |
| 정본 셸 | 아래 판 하나지만 여전히 3층 | '시트 하나 + 타임라인 하나' 그대로 | 셸 변화 없음 |
| 크기 | M | M~L | S~M |

- **합치기안을 버린 이유:** 창 셋을 '판 하나'로 이름만 묶었을 뿐 세 층(자막·타임라인·탐색)이 그대로 쌓인다. 지구 (가) 수치가 높은 것은 반투명 자막(pointer-events:none)을 지구로 센 잣대 때문이고, 눈에 보이는 (나)로는 추천안보다 낮다(half 48 vs 51, 지점 카드 37 vs 40). 가져온 것: `right` 금지(landOn), 크레딧 먼저 두는 순서, ▾ 표적은 위로만, 서브 @media(389) 금지, 360 영어 89 발견.
- **최소위험안을 버린 이유:** 스스로 적었듯 지구를 늘리지 않고(±2%p) 창 수도 그대로다 — PD "창이 너무 많이"에 답하지 못한다. 가져온 것: 숫자를 :root 한 곳에 두는 자리표(`--ts-gap` 하나만 조절), full 시트 천장 `--top-reserve`, ▾ 이름 바꾸기, '상태에 따라 높이가 바뀌는 접기는 넣지 않는다'(알약이 손가락 밑에서 뛴다).
- **정본안에서 고친 것:** 1줄 칩 → 2줄(402 에서도 시각이 잘렸다, 실측), 알약 `left/right 8` → `left + width`(landOn), #hud 를 폰에서 영영 숨기지 않고 ▾ 펼침·하위 뷰 예외로 남김, T 는 선택 단계로 뺌, B4 는 정본안 그대로.
