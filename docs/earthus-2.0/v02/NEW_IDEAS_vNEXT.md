# New Ideas Added in v0.2

These ideas do not change the Earthus 2.0 North Star. They reduce cost, reveal uncertainty, improve trust or create paid value from the same verified data.

## Implemented foundations

### 1. Truth Budget Engine

Maximum visual fidelity is capped by evidence type, spatial resolution, confidence, rights, device and thermal state. It prevents a low-resolution aggregate from silently becoming a detailed 3D object.

### 2. Visual Semantic Linter

Checks manifests for misleading visual semantics: red reserved for official/verified risk, forecast not styled like observation, simulations labeled, and estimated distributions carrying their badge.

### 3. Fail-Soft Scene Profile Compiler

Produces an honest fallback when a requested scene cannot run. It converts vectorless flow to scalar field, actual-grid-free towers to aggregate clusters, and heavy volume to shells/static modes rather than showing fabricated or broken scenes.

### 4. Trust Ledger Drill-down

Every Earthus analysis or narrative output can expose supporting evidence, counterevidence, source/time/provenance and a supported/contested/unsupported state. This becomes the `EVIDENCE` panel and a strong premium/professional differentiator.

### 5. Satellite Product & Tile Broker

Selects the source per region, tile, product, channel, time, day/night, viewing angle, rights and health. It avoids one fixed global ranking and supports GK-2A, Himawari, Meteosat/MTG, GOES and VIIRS roles correctly.

### 6. Procedural Cloud Detail Synthesizer

Generates deterministic high-frequency visual texture from compact Cloud State. It never changes meteorological coverage or creates new cloud cells, so it improves beauty without multiplying archive storage.

### 7. Delta Cloud Keyframe Pack

Stores periodic full Cloud State keyframes plus validated deltas. This can materially reduce NAS growth while preserving replay, subject to reconstruction checks.

### 8. Event Capsule Builder

Packages high-value typhoon, heavy rain, snow, wildfire-smoke and forecast-failure cases with source manifests, model versions, observations and narrative evidence. Capsules support Time Machine, model training, public stories and Control reports.

### 9. Replay Rehydration Engine

Reconstructs temporary service tiles from archived canonical versions only after processor/schema compatibility checks. NAS remains cold storage and is never a live dependency.

### 10. Observation Gap Lens

Turns “where Earthus does not know” into a visual data layer. It shows observed coverage, model dependence, freshness and mapping quality instead of treating missing data as safe or normal.

### 11. Country Data Passport

Compiles data, rights, terrain, localization, performance and QA readiness for each country. It drives Country Unlock honestly and prevents funding alone from opening an incomplete country.

### 12. Cost-to-Value Scheduler

Measures collector/storage/egress/compute cost against user value and demand. Non-safety jobs may be downsampled or deferred under budget pressure; official safety jobs remain protected.

### 13. Champion/Challenger by region and horizon

A single global weather or crowd model is not always best. The selector evaluates skill and calibration by location, domain and lead time before promotion.

### 14. Offline Trip Pack

Creates a bounded offline bundle for a selected trip: official safety, weather, itinerary and POIs first; premium intelligence only when entitled. It improves travel reliability and can reduce repeated network use.
