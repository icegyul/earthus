# EARTHUS 2.0 v0.3 — Additional Product/Engineering Ideas

These are optional additions that use the same verified data and do not change the North Star.

## 1. Earth Memory Index
Instead of opening the NAS archive as a file browser, Earthus indexes notable changes by place, event, variable and confidence. A user can ask for “the last time Seoul had a similar cloud/rain/crowd pattern” and the Analog Retrieval Engine returns evidence-linked capsules.

## 2. Confidence Horizon Ribbon
The global timeline can display a thin confidence ribbon: observed segment, provider forecast segment, Earthus forecast segment and long-range uncertainty. It gives one visual answer to “where does observation end and forecast begin?” without adding another panel.

## 3. Data Scarcity Mode
Country Data Passport can expose a public “coverage view” for unlocked-but-incomplete countries. Instead of hiding missing layers, Earthus makes gaps visible and invites Country Support specifically for missing data categories.

## 4. Event Auto-Capsule
When official warning + high-impact signal + user interest threshold are met, create an archive candidate automatically. It remains CANDIDATE until retention/cost/rights rules approve long-term preservation.

## 5. Edge Preview Cache
For high-demand public scenes, precompute only tiny preview payloads at the CDN edge. Full premium analysis remains server-side/on-demand. This keeps the first interaction fast without storing every heavy result.

## 6. Evidence Diff
When a forecast changes materially, show what changed: model agreement, official forecast, observed trend, source freshness or event input. This is more valuable than simply saying “forecast updated.”

## 7. Scene Cost HUD for developers
A hidden development-only overlay shows active engine ownership, tile count, GPU resources, requests, frame cost and estimated egress. It directly supports the One Data Hero and thermal rules.

## 8. Local Authority Override Registry
For countries with multiple official agencies, do not hard-code one source globally. Maintain a country/domain authority registry so warnings, cyclone tracks, air-quality standards and tide products resolve by jurisdiction.
