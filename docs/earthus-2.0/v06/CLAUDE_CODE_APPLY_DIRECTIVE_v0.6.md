Do not recreate existing v0.2-v0.5 engines. Search the repository, Engine Catalog v0.6 and Algorithm Catalog v0.6 first. NEW code without Gap Evidence is rejected.

## Production completion evidence
Each slice must provide:
- USED_ENGINE_IDS / USED_ALGORITHM_IDS
- reused files and adapters
- actual provider sample or explicit source-disabled state
- browser screenshots/video
- truth/provenance evidence
- mobile scene budget
- dispose/network regression
- no fabricated coordinates, directions or source attribution

- 300 news pins on global scene
- calling news/NGO reports OBSERVATION
- guessing NGO action coordinates
