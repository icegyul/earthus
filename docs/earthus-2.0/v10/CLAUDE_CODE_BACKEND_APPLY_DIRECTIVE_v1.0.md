# CLAUDE CODE — EARTHUS BACKEND v1.0 PRIMARY DIRECTIVE

1. 기존 Engine/Algorithm ID를 먼저 검색한다. 새 파일을 만들기 전에 Reuse Decision을 기록한다.
2. 한 번에 Provider 하나만 Vertical Slice로 구현한다.
3. 기존 운영 Parser를 재작성하지 않는다. v1.0 Backend Contract를 Adapter로 감싼다.
4. 실제 Secret이 없으면 Provider를 DISABLED로 두고 Mock 완료 처리하지 않는다.
5. Raw Receipt/Schema/Watermark/Idempotency/Last-Good/Internal API/Runtime Probe 증거가 없으면 완료 금지.
6. 관측·공식예보·공식경보·모델·Earthus 파생·시뮬레이션 Truth Class를 보존한다.
7. 안전 데이터는 무료이고, cost/fatigue/entitlement가 공식 안전정보를 막지 않는다.
8. 완료 보고서 필수: USED_ENGINE_IDS, USED_ALGORITHM_IDS, REUSED_FILES, NEW_FILES, DATA_EVIDENCE, RUNTIME_EVIDENCE, TEST_RESULTS, ROLLBACK.
