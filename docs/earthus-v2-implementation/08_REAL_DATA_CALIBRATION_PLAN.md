# Real-data calibration plan

The code is intentionally parameterized. The following values are not frozen until live data is measured: Discovery weights, minimum signal coverage, Event Fusion distance/time thresholds by domain, Best Window weights by activity, pollution transport step/resolution, analog feature scales, model promotion thresholds, Pulse relevance weights, notification thresholds.

Calibration must use recorded input/output pairs and report dataset/time range, missingness, provider revisions, region, metric and sample size. Competition claims use measured values only.
