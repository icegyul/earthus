# EARTHUS 3D 지구·데이터 비주얼·무료/유료 서비스 통합 기획서 v1.0

기준일: 2026-08-25

> 이 문서는 현재 대화에서 확정된 제품 방향, 시각 언어, 기술 구조, 구독 경계, 구현 한계를 다른 EARTHUS 마스터 기획에 병합하기 위한 통합 보강본이다.

## 1. 최종 정의

Earthus는 지도 위에 데이터를 얹는 서비스가 아니라, 사용자가 메뉴를 선택하면 지구 자체가 그 데이터의 형태로 변하는 살아 있는 4D 비주얼 지구 플랫폼이다.

- 기본 화면: 아름답고 차분한 3D 지구, 바다, 대기, 가벼운 현재 구름, 최소 UI
- 메뉴 선택: 인구는 봉우리, 이동은 빛의 흐름, 단층은 지하 구조, 비는 강수와 후속 물길, 위험은 펄스와 파동으로 전환
- 무료: 공공데이터 기반 현재 기상, 일반 예보, 특보, 뉴스, 안전 정보, 55개 메뉴 기본 비주얼
- 유료: 원인, 과거, 미래, 비교, 고해상도, 개인 위치·일정 영향, 맞춤 알림, 행동 추천, 관제

## 2. 확정 원칙

- 모든 데이터 비주얼은 메뉴를 눌렀을 때만 활성화한다.
- 공식 재난 경보와 대피 정보는 무료다.
- 55개 메뉴는 공통 엔진 8종을 조합한다.
- 눈에는 모두 3D로 보여도 내부는 LOD·셸·볼륨·리본·타일·입자를 혼합한다.
- 관측·예보·추정·시각화·시나리오를 구분한다.
- 한국·인도 인구밀도 레퍼런스는 구조만 참고하고 직접 복제하지 않는다.
- 흰색+보라색 데이터 조각을 브랜드 기본으로 고정하지 않는다.
- 복잡한 지하 단면은 Future Vision이며, 해구 엔진이 먼저다.

## 3. 공통 비주얼 엔진

- **DATA RELIEF**: 양·밀도·집중도를 지형 높이·봉우리·섬유로 표현 — 인구, 관광, 혼잡, 강수량, 적설, 건물 밀도
- **DATA FLOW**: 방향·속도·이동량을 빛 리본·광섬유·궤적으로 표현 — 바람, 해류, 사람, 교통, 항공, 선박, 물류
- **DATA FIELD**: 연속적인 지표 상태를 재질·광택·거칠기·낮은 높이장으로 표현 — 기온, 습도, 토양수분, 수온, 가뭄, 식생
- **DATA VOLUME**: 공간을 차지하는 현상을 체적·안개·커튼·입자로 표현 — 구름, 비, 눈, 황사, 연기, 오염, 안개
- **DATA NETWORK**: 시설과 경로의 연결·활성·병목을 네트워크로 표현 — 도로, 철도, 항로, 하천, 통신, 전력, 물류
- **DATA PULSE**: 시점과 위치가 있는 사건을 파동·펄스·확산으로 표현 — 지진, 낙뢰, 화산, 산불, 뉴스, 특보
- **DATA ORBIT**: 지구 주변의 위치 관계·궤도·가시권을 공간적으로 표현 — 위성, ISS, 로켓, 우주쓰레기, 일식
- **DATA STORY**: 과거·현재·예측을 카메라와 시간축으로 연결 — 태풍, 도시 성장, 산불, 철새, 관광 혼잡, 발사 이벤트

## 4. 3D 엔진·성능

- 전지구는 저정밀 지형·구름 셸·강수 커튼, 확대 지역만 고정밀 DEM·제한 볼륨·근거리 입자를 사용한다.
- 모바일은 저·중·고 3개 구름 셸, 데스크톱은 1/2 해상도 체적 구름을 사용한다.
- 5~7일 구름 예보는 관측 구름을 단순 이동시키지 않고 모델 자료로 재구성한다.
- 구름, 강수, runoff, 하천 유량, 홍수는 서로 다른 엔진이다.
- 원본 GRIB는 서버에서 수집·정규화·타일링하고 클라이언트는 Earthus 타일을 재생한다.
- GPU 3프레임, RAM 주변 프레임, 디스크/브라우저 캐시의 3계층 캐시를 사용한다.
- IDLE/ORBIT/PLAYBACK/SETTLING/BACKGROUND 렌더 상태 머신을 사용한다.
- Cesium과 Three.js를 동시에 상시 구동하지 않고 비활성 자원을 실제 해제한다.

## 5. 비주얼 스타일

- **기본 지구**: NASA형 사실성보다 조금 더 정돈된 반사실적 PBR 지구.
- **국가 데이터**: 데이터 조각 구조를 사용하되 흰색+보라색을 고정하지 않고 흑연+구리/호박, 광물+청록, 자연 지표+단일 강조색 등으로 재설계.
- **기상·해양**: 실제 지구 위에 흐름 리본, 체적 구름·연기·안개, 강수 커튼, 열·수분 재질을 사용.
- **재난·지질**: 현재는 지표·실제 단층선·진원·깊이·절제된 파동. 정밀 지하 단면은 미래 비전.
- **유료 분석**: 짙은 흑연·남청 배경, 선택 지역 강조, 청록·호박·구리 정밀선, 적색은 공식 위험에 한정.
- **UI**: 기본은 거의 숨기고 데이터 옆에 필요한 정보만 직접 표시.

## 6. 구현 현실성과 해구 게이트

해구는 전지구 지형 LOD, 음수 고도, 해수면/해저 분리, 클리핑, 수중 카메라, 수심 조명, 모바일 성능을 검증하는 핵심 게이트다. 해구가 구현되지 않으면 정밀 섭입판·지하 단면을 현재 목표에 넣지 않는다.

### 현재 구현 목표
- 지진: 3D 지표 + 실제 단층선 + 지하 진원 + 규모/깊이 + 짧은 파동
- 쓰나미: 공식 경보 + 해안 영향 + 도달시간 + 대피
- 비: 강수 커튼 + 누적강수; runoff·하천은 후속
- 해류: 표층 리본 + 와류; 깊이별 흐름은 해구 엔진 이후

### Future Vision
- 정밀 단층면, 섭입판, P/S파 공간 전파, 응력장
- 수심별 쓰나미 전파, 도시 침수·배수 시뮬레이션
- 깊이별 해류, 수중 단면, 심해 탐사

## 7. 개발 로드맵

- **Phase 0 — 기준 고정**: 기본 지구, 색·재질·카메라, 데이터 상태 라벨, 성능 측정 도구 → 시각 스타일 바이블 + 실기기 기준
- **Phase 1 — 핵심 차별화**: 3D Terrain Relief, 인구 봉우리, 현재 구름, 바람 리본, 기본 국가 선택 → Earthus가 케이웨더형 지도와 다르게 보이는 최소 제품
- **Phase 2 — 기상 시간축**: 5~7일 구름·바람·기온, 강수 커튼, 관측→예보 전환, 서버 타일 → Living Earth 기상 경험
- **Phase 3 — 해양·해구**: 파고·표층 해류, Bathymetry, 해구 Level 1~2 → 해저·지하 확장의 기술 기반
- **Phase 4 — 데이터 스토리**: 관광·교통·항공·선박·뉴스·국가별 자동 스토리 → 무료 반복 사용과 유료 진입
- **Phase 5 — 심층 Intelligence**: 비교·개인화·관제·보고서, 제한 지역 지질·수문 심화 → 구독 및 B2B 분석

## 8. 5대 기술 검증

- **1. 3D Terrain Relief**: 땅이 지구 전체·국가·도시 확대에서 아름답고 안정적으로 전환되는가. 완료 기준: LOD 팝핑 없음, 수직 과장 표시, 모바일 프레임 유지
- **2. Trench/Bathymetry**: 0m 아래 해저지형과 해수면을 분리해 해구를 실제 깊이로 표현할 수 있는가. 완료 기준: 수심 타일, 클리핑, 카메라, 메모리 검증
- **3. Population Sculpture**: 실제 인구 격자·행정 데이터를 봉우리/섬유로 변환할 수 있는가. 완료 기준: 값 보존, 로그 스케일 표시, 국가/도시 LOD
- **4. Cloud/Wind**: 구름 셸·반볼륨과 바람 리본을 모바일에서 장시간 재생할 수 있는가. 완료 기준: 30fps 목표, 발열·메모리 누수, 저전력 축소
- **5. Earthquake Depth**: 지표 아래 좌표에 진원과 깊이를 자연스럽게 배치할 수 있는가. 완료 기준: 카메라·클리핑·단층선·파동의 정확한 관계

- **38. 너울 (swell)** — Before: 너울 높이와 주기를 색상·화살표로 표시 / After: 먼 폭풍에서 생성된 긴 파도열이 해양을 가로질러 해안에 도착하는 시간과 방향을 긴 3D 리본 파동으로 표현한다. / 무료: 현재 너울·주기·기본 해안 영향 / 유료: 발원 폭풍, 해안별 도착시간, 낚시·해변·서핑 위험 맞춤 알림 / P1, GPU H, NEXT
- **39. 해류 (current)** — Before: 바다 표면의 2D 입자선으로 흐름 표시 / After: 현재 목표는 표층 해류의 3D 리본과 와류다. 깊이별 해류·수중 단면은 해구/수중 엔진 이후 확장한다. / 무료: 현재 표층 해류·기본 흐름 / 유료: 깊이별 층, 표류·선박·어업·해양쓰레기 경로, 과거·예측 비교 / P0, GPU H, STAGED

### F. 지표·관측 (10개)

- **40. 안개 (fog)** — Before: 안개·시정 값을 회색 반투명 평면으로 표시 / After: 안개가 계곡·강·해안·도시 저지대를 따라 낮게 흐르고 시정 거리가 공간 링으로 줄어드는 장면을 만든다. / 무료: 현재 안개·시정·공식 경보 / 유료: 해소 예상, 도로·공항·산행·촬영 경로 영향 알림 / P1, GPU H, NEXT
- **41. 토양 수분 (drought)** — Before: 토양수분을 갈색~파랑색 평면으로 표시 / After: 젖은 땅은 윤기와 생명감을, 마른 땅은 거친 재질·미세 균열·식생 퇴색으로 변해 토지 상태가 지구 자체에 나타난다. / 무료: 현재 토양 수분·기본 등급 / 유료: 누적 가뭄·농업·산불 위험, 과거 평년·회복 시나리오, 관심 농지 알림 / P1, GPU M, NEXT
- **42. 기압 배치 (pressure)** — Before: 등압선과 H/L 기호를 평면 지도에 표시 / After: 고기압은 대기 돔, 저기압은 대기 그릇처럼 보이고 바람이 그 주변을 휘돌아 날씨 변화의 원인을 공간적으로 설명한다. / 무료: 현재 기압 배치·등압선·기본 해설 / 유료: 상층 흐름 결합, 저기압 발달·이동, 강수·태풍 원인 스토리와 모델 비교 / P1, GPU M, NEXT
- **43. 비구름·강수 (rain)** — Before: 레이더 강수 색상을 평면 격자로 표시 / After: 현재 목표는 실제 강수 자료 기반의 강수 커튼과 지형 접지 표현이다. 지표 유출·하천 합류·범람은 별도 수문 단계로 분리한다. / 무료: 현재 강수·공식 레이더·기본 이동·경보 / 유료: 시작·종료, 누적량, 유역 유출·하천 도달, 내 위치·일정 영향 / P0, GPU H, STAGED
- **44. 지상 관측소 (landobs)** — Before: 관측소 위치를 점과 팝업으로 표시 / After: 관측소가 지표 위 센서 기둥으로 서고 기온·바람·강수·기압이 높이·방향·맥동으로 실시간 반응한다. / 무료: 실측 관측소 값·시각·기본 비교 / 유료: 다중 관측소 추세, 품질검사, 관심지역 보간·변화 알림 / P2, GPU L, LATER
- **45. 영국 예보 (ukfc)** — Before: 36개 지점 예보를 아이콘·숫자로 표시 / After: 영국 지형 위 36개 지역의 날씨가 작은 구름·비·바람·온도 조각으로 동시에 변하고 하루 스토리로 재생된다. / 무료: 36곳 기본 예보와 국가 시각화 / 유료: 지역 비교·일정·여행 경로, 모델 차이, 관심도시 알림 / P2, GPU M, LATER
- **46. 관측 공백 (coverage)** — Before: 관측소가 적은 영역을 회색 마스크로 표시 / After: 관측 신뢰도가 높은 곳은 촘촘한 빛의 메시, 공백은 어두운 균열·성긴 그물로 보여 “모르는 곳”을 데이터로 만든다. / 무료: 관측망 밀도·기본 공백 표시 / 유료: 변수별 신뢰도, 모델 의존도, 분석 결과의 불확실성 지도·리포트 / P2, GPU L, LATER
- **47. 해양 부이 (buoy)** — Before: 부이 위치를 점·아이콘과 팝업으로 표시 / After: 바다 위 3D 부이가 실제 파도에 따라 상하로 움직이고 수온·파고·바람이 주변 링과 기둥으로 반응한다. / 무료: 현재 부이 실측·시각·기본 그래프 / 유료: 추세·임계 알림, 인근 해역 보간, 낚시·서핑·항로 영향 / P1, GPU M, NEXT
- **48. 대기오염 실측 (airkr)** — Before: 측정소별 등급 점과 숫자를 표시 / After: 도시의 실측 센서 타워에서 실제 농도에 비례한 공기 기둥이 올라오고 주변 모델 부피와 차이를 비교한다. / 무료: 전국 실측소 값·등급·시각 / 유료: 동네 추세·모델 차이·개인 노출, 관심 측정소 조건 알림 / P1, GPU M, NEXT
