## 3. 운영 화면 검증

- query 없는 `/`: `main.js?v=20260812-earthview1`, 아름다운 Earth, 로딩 종료
- Style URL: 레이어 메뉴 복원
- Data URL: `temp` chip on과 격자 canvas 복원
- Evidence URL: 좌표 정규화, 뒤로가면 Data, 앞으로가면 Evidence 복원
- TPW: 전체 레이어에 `blocked`로 표시, 클릭 뒤에도 on=false·URL 불변·network 요청 없음
- 혼합 Earth+AETHERUS: Earth Data만 남기고 AETHERUS query 제거
- 혼합 Earth+ocean: `?ocean=1`만 남기고 해구 HUD 복원
- 순수 AETHERUS 화성: AETHERUS v3 URL 정규화와 화성 관측 정보 복원
- 순수 해구: 7개 연결 영역·면적·GEBCO 한계문구 HUD 복원
- 신규 warning/error 0. 인증 로그의 세션 없음 info만 존재

로컬에서는 390×844 query 없는 Earth와 Data URL도 확인했다. 운영 in-app 브라우저는
1280×720 고정이라 실제 390px 운영 기기 검증과 Safari/구형 iPhone 검증은 남은 gate다.

## 5. 롤백 기준

배포 전 기존 파일 SHA-256은 작업 로그에 보존했다. 신규 `gridmath.js`,
`earth-route-state.js`, `earth-view-state.js`는 배포 전 운영에서 HTTP 403이었다.

즉시 완화는 `index.html`의 main revision을 이전 운영본으로 되돌리고 이전 정적 파일을
재업로드한 뒤 같은 경로를 무효화하는 방식이다. 삭제는 복구 검증 뒤 별도 실행한다.
실제 복구 rehearsal과 RTO 기록은 아직 하지 않았으므로 남은 gate로 둔다.

배포 계정에는 `cloudfront:GetInvalidation` 권한이 없어 무효화 상태 조회는 AccessDenied였다.
성공을 추정하지 않고 cache-busting 운영 응답 15개와 로컬 SHA-256 일치로 반영을 증명했다.
