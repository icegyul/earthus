## 1. 배포 결과

기온·내일 최고/최저·기압·바람·SST·SST 편차·파고를 단계색과 같은 원격자 등치선,
선값 라벨, 도시 최근접 원격자값, 지점 Evidence로 판독할 수 있게 운영 반영했다.
query 없는 `/`는 여전히 아름다운 지구이며 수치 패널·등치선·활성 데이터층이 없다.

최초 배포 뒤 모바일 바람 검수에서 두 문제를 발견했다.

1. 같은 탭에서 기압→바람 URL로 이동하면 활성 칩에 기압이 남았다.
2. Earth Data 딥링크에서도 첫 화면 intro가 시작되어 Cesium 유휴 렌더가 남았다.

보완 커밋은 단독 바람 Data View에서 이전 연속 색면 상태를 끄고, Earth Data/Evidence
딥링크에서는 아름다운 첫 화면 전용 intro를 시작하지 않는다. 기온+바람이 목적인
`지금/내일` 시간 프리셋은 예외로 보존한다.

- 등치선: 254 paths, 라벨 10
- 판독 패널: x=7..383, width=376px

- 3초 정지 전/후 Cesium 누적 렌더: 48→48, 차이 0
- entry: `main.js?v=20260812-contours2`

query 없는 운영 `/` 최종값:

- `earthView=earth`
- 활성 데이터층 0
- Readability hidden

`meteo 503` warning 하나는 이 배포보다 앞선 원격 날씨 응답 이력이며 PR-06 오류가 아니다.

## 4. 파일 무결성과 헤더

최종 보완 배포 4개 파일은 cache-busting GET의 SHA-256이 로컬과 일치했다.

| 운영 경로 | SHA-256 |
|---|---|
| `/index.html` | `5a072912c4afa92cbf9df0fcb0f9fd07a10152854f0a3fde73bb3ccf727b5d56` |
| `/js/main.js` | `4149983254448360a1fae75c164cf17608b0fc1cd6f6127abdee468e2659b599` |
| `/js/earth-view-state.js` | `06d159bd013f05c79f2a1fd9da9a708d869f84d8b5643fc88050861ffc3ae506` |
| `/js/store.js` | `05d5cb255b64d3c47397edb71962d66c2f3a527b4fd9046f4143e32934ace0e4` |

HTML은 `text/html; charset=utf-8`, JS는 `text/javascript; charset=utf-8`, 전부
`Cache-Control: no-cache`를 확인했다. 배포 계정에는 `cloudfront:GetInvalidation` 권한이
없어 waiter 상태 조회는 거부됐지만, 무효화 생성은 성공했고 CDN GET의 실제 바이트·entry가
최종본과 일치하므로 운영 반영 자체는 별도로 입증됐다.

## 5. 남은 승인 관문

- TPW 운영 객체는 여전히 403이며 `TPW_READY=false`다. 실제 NOAA 파일·권리·시각·화면
  검수 전에는 켜지 않는다.
- Safari·구형 iPhone 10~15분 실제 기기 열/배터리 검수는 장비 부재로 미완료다.
- PR-07 Decision Core 전이므로 Activity/Personalization/Reservation 판단을 만들지 않았다.
- AETHERUS 파일, 판매 flag, SNS 자동 게시, PR-01/02 authoritative reader는 건드리지 않았다.

## 6. 롤백

`CONTINUOUS_LAYERS.md` 5장의 정적 파일 목록을 이전 커밋으로 올리고 올바른 Content-Type,
`no-cache`, CloudFront 무효화를 적용한다. TPW flag나 Lambda를 롤백 절차에 섞지 않는다.
