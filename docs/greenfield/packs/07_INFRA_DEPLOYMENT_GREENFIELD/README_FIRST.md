# EARTHUS V2 Infrastructure / Deployment — Greenfield

This package defines the zero-start infrastructure boundary without embedding credentials.

Recommended base: static/PWA client + Cesium, AWS Lambda/EventBridge ingestion, S3 raw/public object planes, CloudFront delivery, Supabase/PostgreSQL control/index plane. Use actual measured needs before adding GPU workers.

Deployment cannot be called complete until real provider, browser, physical device, performance/thermal, rights and rollback evidence pass.
