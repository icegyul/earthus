# EARTHUS V2 Frontend / 3D App Source — Greenfield

This ZIP contains executable frontend/source modules, not screenshots-only handoff material.

Included:
- `prototype/v2` HTML/CSS/JS application shell reconstructed from the add-only foundation source.
- frontend-v10 SceneIntent/SceneState/transaction runtime where present.
- core/visual/geo/home modules needed to build the interactive Earth UI.
- Greenfield Physical-3D canonical source overrides.
- recovered Planet/Terrain/Ocean/Cloud renderer source artifacts.

Canonical behavior:
- one Cesium Viewer;
- GLOBAL is already physical/data-driven 3D;
- zoom increases 3D detail and regional data/compute, never photo-to-3D;
- raster/satellite imagery is observation/material input, not the final world;
- old SHELL/STATIC_SHELL behaviors in historical source are not production-final fallbacks and must be replaced by the Greenfield policy before acceptance.

This source is a reconstructed foundation, not a byte-for-byte archive of the latest live GitHub branch. Greenfield build can start here; live-repo reconciliation is a separate path when the current repository is available.
