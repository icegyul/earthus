# EARTHUS ICON SYSTEM — MASTER GENERATION PROMPT v1.0

기준일: 2026-09-12
적용 범위: EARTHUS V1 / EARTHUS V2 / 향후 신규 메뉴

## 1. Design Goal

Create a premium EARTHUS icon family for a living-Earth data platform.
Icons must feel like polished scientific interface objects rather than generic emojis or stock UI glyphs.

Core visual direction:
- premium glossy semi-3D circular illustration
- soft gradient depth
- glass / polished surface feel
- subtle atmospheric glow
- clean modern geometry
- high recognition at 24–64 px
- deep navy / charcoal UI compatibility
- natural Earth colors with restrained luminous accents
- consistent silhouette, lighting direction, and visual weight across the family
- no cartoon character style
- no generic stock icon style
- no photorealistic miniature renders
- no unnecessary text inside the icon
- no people unless the subject itself requires population/society representation

## 2. Reference Mood

Use the current EARTHUS approved reference image as the visual source of truth:
- circular weather/environment app-icon composition
- layered blue/cyan/purple/green/orange gradients
- clear subject symbol embedded into a small illustrated scene
- polished light rim around the circular surface
- subtle depth without heavy skeuomorphism

The result should look like one coherent product family even when icons represent very different scientific domains.

single centered circular icon, transparent background outside the circle, no label, no border outside the circular icon, no extra objects.

## 5. States

Default:
- normal brightness
- no heavy glow

Hover:
- +5–10% perceived brightness
- subtle lift / luminous rim

Active:
- thin luminous ring
- restrained blue/cyan glow
- small scale emphasis only

Disabled:
- desaturated
- reduced glow
- keep recognition intact

## 6. Sizing

Master artwork: 1024px or larger.
Runtime exports:
- 128px reference
- 64px desktop
- 32px compact
- 24px mobile

Maintain identical visual center and silhouette across all sizes.

## 7. EARTHUS Navigation Rule

Primary navigation icons represent the first-order observable Earth data/phenomena.

DO:
- Temperature
- Precipitation
- Wind
- Sea Level
- Sea Temperature
- Typhoon
- Glacier
- Wildfire
- Earthquake
- Satellite
- Ecosystem
- etc.

DO NOT:
- create a large standalone primary "Intelligence" menu icon
- create a large standalone primary "Simulation" menu icon

Instead:
Primary Data → anomaly/change/context → inline Intelligence action → report → Simulation for Pro+.

Intelligence and Simulation are workflow stages, not primary subject categories.

## 8. V1 / V2 Application Rule

V1:
- preserve the familiar direct menu behavior
- replace legacy/generic symbols with the EARTHUS icon family
- keep the menu visually light and immediately recognizable

V2:
- primary data menu on the left
- icon + label
- desktop and mobile must share the same icon registry
- active subject gets clear state
- related secondary overlays may coexist only when semantically compatible
- Intelligence appears inside the selected subject context
- Simulation follows Intelligence as the advanced next step
