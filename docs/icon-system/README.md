Complete handoff package for EARTHUS V1 + V2.

- 4 visual reference boards.
- Master generation prompt for future icons.
- Primary menu registry.
- 55-layer mapping.
- Claude Code implementation directive in Markdown and DOCX.
- V1/V2 application directive.
- Intelligence/Simulation workflow rules.

## Important
The 36 primary icon set is the shared semantic system.
The 55-layer mapping reuses parent/nearest semantic icons for sublayers where a dedicated primary icon is not needed.

Primary UX:
DATA → ANOMALY/CONTEXT → INTELLIGENCE → REPORT → SIMULATION → USER AI

Intelligence and Simulation are contextual workflow stages, not standalone primary menus.
