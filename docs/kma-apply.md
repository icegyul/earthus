# 기상청 API허브 — 남은 활용신청 253건 (2026-07-27 기준)

## 먼저 알아 둘 것

- 신청은 **즉시 승인**된다. 심사 대기가 없다. (실측: 지점정보 신청 직후 바로 200 응답)
- 유효기간은 **2년** (2026-07-27 ~ 2028-07-27). 만료 전 재신청이 필요하다.
- 한 탭 안의 여러 버튼이 **같은 번호**를 쓰는 경우가 있다. 번호 기준으로 세면 중복이 없다.
- 신청 창은 `window.open` 으로 뜨기 때문에 **팝업 차단에 막힌다**.
  아래 주소를 직접 열면 차단과 무관하다.

      https://apihub.kma.go.kr/APIUse.do?seqApi=<번호>

- 호출 한도: **하루 20,000회 / 5GB**. 수집 주기를 여기에 맞춰야 한다.
  (현재 사용량 183회 / 0.05GB — 여유가 많다)

## 자동 신청 스니펫

⚠️ 이건 **직접 실행하셔야 합니다.** 제가 대신 253건을 연속 제출하는 것은
안전장치에 막혔고, 우회하지 않았습니다. 아래는 같은 일을 하는 코드입니다.

사용법: 기상청 API허브에 **로그인한 상태**에서 아무 페이지나 연 뒤
Chrome 개발자도구(⌥⌘I) → Console 에 붙여넣고 Enter.

```js
// 활용분야 = 학술/연구(CD00009), 활용목적 = 기상현상 분석(CD00054)
const PURPOSE = '지구관측 데이터 시각화 웹앱(earthus)에서 국내 기상·해양·고층 관측자료를 '
  + '지도와 그래프로 일반에 공개합니다. 출처를 표기하며 원자료를 그대로 재배포하지 않고 '
  + '집계·시각화한 형태로 제공합니다.';

const IDS = [/* 아래 목록의 번호를 붙여넣으세요 */];

(async () => {
  let ok = 0, skip = 0;
  for (const id of IDS) {
    try {
      const r = await fetch('/requestUseApi', {
        method: 'POST', credentials: 'same-origin',
        headers: { 'Content-Type': 'application/json', 'X-Requested-With': 'XMLHttpRequest' },
        body: JSON.stringify({
          seqApi: String(id), useSpcltCd: 'CD00009',
          usePurpsCd: 'CD00054', purpsUseEtc: PURPOSE,
        }),
      });
      r.ok ? ok++ : skip++;
    } catch (e) { skip++; }
    await new Promise(r => setTimeout(r, 250));   // 서버 배려. 지우지 말 것
    if ((ok + skip) % 25 === 0) console.log(`${ok + skip}/${IDS.length} … 성공 ${ok}`);
  }
  console.log(`끝. 성공 ${ok} / 실패·중복 ${skip}`);
})();
```

끝나면 마이페이지에서 건수를 확인하고, 실제로 열렸는지는 API 를 직접 불러 확인한다.
**신청 목록에 있다는 것과 응답이 온다는 것은 다르다** — 반드시 호출해 볼 것.

## 다시 확인하는 법

목록은 시간이 지나면 낡는다. 브라우저 콘솔에서 이걸 돌리면 **지금 남은 것**이 나온다.

```js
const NM={2:'지상관측',3:'해양관측',4:'고층관측',5:'레이더',6:'위성',7:'지진/화산',
          8:'태풍',9:'수치모델',10:'예특보',11:'응용기상',12:'세계기상',14:'항공기상'};
const out=[]; let tot=0;
for (const c of Object.keys(NM)) {
  const t0 = await (await fetch(`/apiList.do?seqApi=${c}`,{credentials:'same-origin'})).text();
  for (const s of [...new Set([...t0.matchAll(/seqApiSub=(\d+)/g)].map(m=>m[1]))]) {
    const t = await (await fetch(`/apiList.do?seqApi=${c}&seqApiSub=${s}`,{credentials:'same-origin'})).text();
    // 신청이 끝난 항목은 openAPIUse 버튼이 사라진다 — 남아 있으면 미신청이다
    const ids = [...new Set([...t.matchAll(/openAPIUse\((\d+)\)/g)].map(m=>m[1]))];
    if (ids.length) { tot += ids.length; out.push(`${NM[c]}\t${c}/${s}\t${ids.join(',')}`); }
  }
}
console.log(out.join('\n')); console.log('미신청', tot, '건');
```
