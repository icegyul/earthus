## 1. 접미·접두 결합안 평가

**결론: 상표 리스크 저감 수단으로는 사실상 무효.** 도메인·스토어명 확보 수단으로만 의미가 있습니다.

한국 유사판단은 **요부(要部) 관찰 + 칭호 중심**입니다. 식별력이 약한 부가어는 요부가 되지 못하고 `earthus`가 그대로 요부로 남습니다.

| 안 | 요부 | 09류 선등록과의 칭호 유사도 | 평가 |
|---|---|---|---|
| earthus one | EARTHUS | 변화 없음 | 리스크 저감 ≒ 0 |
| earthus live | EARTHUS | 변화 없음 | 리스크 저감 ≒ 0. 'live'는 서비스 성질 표시로 식별력 없음 |
| earthus globe | EARTHUS | 변화 없음 | 'globe'는 지구본=지정상품 성질 기술 → 식별력 부정 가능 |
| **us.earth** | US EARTH | **어순 도치일 뿐, 관념 동일** | **오히려 EARTH,US에 더 근접. 배제 권장** |
| earthus & ○○ | – | – | 이미 배제 결정(옳음) |
| earthusphere / earthuscope | 전체가 1단어 | **새 칭호·관념 발생** | 유일하게 유사 탈피 효과 있음. 단 발음 길어짐(요건 1 위반) |

**실무적 함의:** 결합으로 리스크를 낮출 수 없다는 건 나쁜 소식이 아닙니다. 애초에 **지정상품이 다르므로 결합 없이 순수 `earthus`로 09·42류를 출원하는 것이 최선**입니다. 결합안은 순수 earthus가 거절됐을 때의 2안이 아니라, 그냥 다른 이름입니다.

## 3. 로고 결합상표 우회 / 42류 선확보 전략

### 3-1. 로고 결합으로 09류 우회 — **실효성 낮음, 오히려 위험**

- 문자 부분에 식별력이 있으면 문자만으로 요부가 되어, 도형을 붙여도 유사 판단을 회피하지 못합니다.
- **더 중요한 점: 선등록 A·B 모두 도형코드 `010502`**(비엔나 도형분류 01.05 = 천체·지구·지구본 계열, 세부 해석은 추정). **지구본 도형을 로고에 쓰면 문자에 더해 도형까지 근접**해집니다.
- → **CesiumJS 지구본 서비스인데 로고에 지구 도형을 쓰면 안 됩니다.** 궤도선·격자·수평선·위성 트레일 같은 추상 모티프로 가야 합니다.

### 3-2. "42류만 먼저" 전략 — **타당하지만 09류를 포기할 이유가 없어짐**

- 42류에 earthus 계열 선등록 0건 확인 → **42류는 거의 확실히 확보 가능**(추정, 심사관 재량 잔존).
- 그런데 09류 선등록 2건의 지정상품이 소프트웨어가 아니므로, **09류도 함께 출원하는 것이 합리적**입니다. 09류를 포기하면 스스로 권리 공백을 만드는 셈입니다.
- **권장: 09류 + 42류 동시 출원.** 09류가 거절되면 그때 42류만 살리면 됩니다(부분거절 제도로 류별 분리 처리 가능).

**관납료** (특허로 수수료 안내 페이지 기재값, 재확인 권장)

| 항목 | 금액 |
|---|---|
| 상표출원료(전자, 1류당) | 52,000원 + 지정상품 가산금 |
| 상표등록료(1류당, 10년) | 201,000원 (2회 분할 시 회당 122,000원) |
| 09+42 2개류 합계(출원+등록) | 약 **506,000원** + 가산금 |
| 대리인 수수료 | 류당 20~40만원 (추정, 시장가) |

**심사 소요기간 — 실측치**
- 박주현 건: 2023.08.08 출원 → 2025.07.25 등록 = **23.5개월**
- 김소연 건: 2020.12.30 출원 → 2022.06.07 등록 = **17.3개월**
- 언론 보도상 상표심사 평균 15개월 이상(2025.01)
- **우선심사 시 약 2개월**(민간 자료, 추정). 단 2024.1.1부터 요건 강화 — "사전검색 실시"는 불인정, **지정상품 전부에 대한 실사용 또는 구체적 준비 증거** 필요. earthus는 8/4 오픈 = 실사용 증거 확보 용이 → **우선심사 요건 충족 가능성 높음.**

## 4. 선등록권자와의 협상 옵션

### (a) 공존동의제 — **확보해두면 좋으나, 필수는 아님**

- 근거: 상표법 제34조 제1항 제7호 단서 / 제35조 제6항, **2024.5.1 시행** (확인)
- 요건: 선등록권자별 **개별 동의서**(성명·법인명, 서명/날인, 특허고객번호, 등록번호). **기한·지역 조건부 동의 불가, 포괄 동의 불가, 표장+지정상품이 모두 동일하면 불가** (확인)
- 제출 시기: 출원 시 / 의견제출통지 대응 시 / 이의신청 답변 시 / 심판 의견서 제출 시
- **김소연·김아름 건은 공유상표 → 2인 전원 동의 필요**
- 사후 리스크: 공존동의로 등록된 상표를 **부정경쟁 목적으로 사용해 혼동을 야기하면 취소심판 대상**(제119조 제1항 제5호의2) (확인)
- **소요/비용 추정:** 협상 2~8주, 관납료 없음, 사례금 0~수백만원. 대리인 통한 접촉 권장.
- **판단: 09류 심사에서 거절이유가 통지된 경우에만 발동하는 "예비 카드".** 지금 선제적으로 접촉하면 오히려 상대에게 이의신청·감시 동기를 부여합니다(**출원공고 전 접촉 비권장**).

### (b) 양수(양도) 협상 — **불필요**

- **A(박주현)**: EARTH,US는 현재 영업 중인 브랜드명 그 자체. 전부 양도 가능성 ≈ 0. 부분(지정상품 분할) 양도를 받아도 **소프트웨어 지정상품이 애초에 없어 살 것이 없음.**
- **B(김소연·김아름)**: 방진마스크 브랜드. 양수 가능성은 상대적으로 높으나 **역시 살 필요가 없음.**
- 이전등록료 기본료 40,000원 + 대리인비. 매수가는 시장 협상(추정 수백만~수천만원).
- **판단: 현 단계에서 예산 배정 불필요.**

### (c) 불사용취소심판 (제119조 제1항 제3호) — **가능하지만 불필요**

| 대상 | 등록일 | 3년 경과 여부 | 청구 가능 시점 |
|---|---|---|---|
| **B. Earth&us** | 2022.06.07 | **경과 ✅** | **지금 청구 가능** |
| **A. EARTH,US** | **2025.07.25** | 미경과 ❌ | **2028년 중반 이후** ← 중요 |

- 청구인 적격: **누구든지** 청구 가능(제119조 제5항). 취소 확정 시 **심판청구일에 소급 소멸**(제6항) (확인)
- 입증책임은 상표권자에게 전환 — 청구인은 유리
- **비용:** 취소심판 청구료 전자 **1류당 240,000원** (특허로 기재값) + 대리인 수수료 200~500만원(추정)
- **기간:** 특허심판원 디자인·상표 심판 **평균 처리기간 7.2개월(2024년, e-나라지표)**. 특허법원 불복 시 +12개월 내외(추정)
- **판단: 방진마스크 vs 지구관측 소프트웨어는 어차피 비유사 → 취소시킬 실익 없음.** 09류 거절통지에서 B가 인용될 경우에만 검토.
- **⚠️ A는 2028년까지 불사용취소가 불가능**하다는 점을 전략에 반영해야 합니다. A가 문제라면 협상 외에 방법이 없습니다.

## 5. 최악의 경우 — 42류만으로 운영할 때 실제 제약

**앱스토어 출시 자체는 막히지 않습니다.** Apple·Google 모두 앱 등록 시 상표등록을 요구하지 않습니다.

실제 제약은 다음 3가지입니다.

## 한국어 이름의 글로벌 확장 리스크 (솔직한 평가)

1. **로마자 표기가 최대 실패 지점이다.** ㅕ(yeo)·ㅡ(eu)·ㅐ(ae)는 영어 화자가 읽지 못한다. 위 13개 중 이 기준을 통과하는 건 `Onbom`, `Dalnuri`, `Duruvi`, `Durubom` 4개뿐이다. 나머지는 국내 전용으로 보는 게 정직하다.
2. **순우리말로 글로벌 성공한 국내 서비스 전례가 사실상 없다.** 카카오·네이버·쿠팡·토스·배민 모두 국내에서 강했고 해외는 별도 브랜드를 썼다. 한국어 이름을 고르는 건 "글로벌 때 리브랜딩한다"를 암묵적으로 받아들이는 선택이다.
3. **의미 전달이 0이다.** 지구 관측 앱이라는 걸 이름이 전혀 알리지 못하므로 초기 마케팅 비용이 영어 조어보다 높다. 반대급부로 브랜드 검색어 독점은 쉽다.
4. **연 ₩39,000 구독 + 2026-08-04 오픈**이라는 조건에서, 오픈 6일 전 리브랜딩은 상표 출원(심사 12~18개월)이 오픈에 못 맞춘다. **출원 즉시 진행하고 오픈은 사용 개시로 가되, 등록 전까지는 ™만 쓰는 것**이 현실적이다.

## 3. 도메인

### 3-A. TLD 선택 — 지구 관측 서비스 기준 **[추정]**
| TLD | 권고 | 근거 |
|---|---|---|
| **.com** | **1순위 (필수 목표)** | 유료 구독 B2C, 테슬라 브라우저 등 주소 직접 입력 상황에서 오타 유입이 가장 적음 |

| **.app** | 유력 대안 | **[확인]** Google Registry가 .app을 **HSTS preload 리스트에 TLD 단위로 등재** → 모든 .app 사이트는 **최초 요청부터 브라우저가 HTTPS 강제**. 별도 헤더 설정 불필요, 유효 인증서 없으면 아예 로드 안 됨. 보안 신뢰 + 앱 서비스 정체성에 부합 |
| **.io** | **비권장** | **[추정]** 영국령 인도양 지역 국가코드에 기반한 지정학적 불확실성이 반복 이슈화됨. 유료 구독 인프라를 10년 단위로 걸기엔 리스크 |
| **.kr** | 보조(리다이렉트용) | **[확인]** 신청인·등록인이 **대한민국에 주소지**를 가져야 등록 가능. 국내 신뢰도용으로만 |

- [ ] **[추정]** 테슬라 차량 브라우저 타이핑 고려 시 **총 12자 이하, 하이픈·숫자 없음, 이중자음 없음**을 하드 조건으로.

### 3-B. 도메인 스쿼팅·오염 확인 (구매 전)
- [ ] **[확인]** **WHOIS 조회** — 등록일, 만료일, 등록기관, 소유 이력. 잦은 소유권 변경은 적신호.
- [ ] **[확인]** **Wayback Machine(web.archive.org)** — 과거 스냅샷 확인. 성인·도박·해킹 페이지 이력이 있으면 브랜드 오염.
- [ ] **[확인]** **스팸/블랙리스트 점검** — Moz Spam Score, 백링크 프로파일(SEMrush 등)로 과거 SEO 조작 흔적 확인.
- [ ] **[추정]** 판매 파킹 페이지가 떠 있으면 스쿼팅 가능성 — 브로커 통해 익명 문의(브랜드 노출 금지, 가격 폭등 방지).
- [ ] **[확인]** 이미 상표권이 있는데 제3자가 선점했을 때의 구제: 국제 gTLD는 **UDRP**(ICANN, 1999.12.1 시행), **.kr/.한국은 KR-DRP** — **인터넷주소분쟁조정위원회(idrc.or.kr)**, 인터넷주소자원법 근거. 한국 위원회는 **ADNDRC 가입 기관이라 UDRP 사건도 처리** 가능.
- [ ] **[추정]** 다만 UDRP는 "상표권이 먼저 있을 때" 무기다. **상표 출원 전에 도메인을 뺏기면 대응 카드가 없다** → 3-C 순서가 중요.

### 3-C. 방어 등록 범위 권고 **[추정]**
- **필수(즉시)**: `이름.com` + `이름.net` + `이름.app` + `이름.kr`
- **권장**: 오타 도메인 2~3개(자판 인접 오타, 이중자음 누락형), `get이름.com` 또는 `이름app.com`
- **불필요**: 수십 개 TLD 싹쓸이. 비용 대비 실익 낮고, 상표권 확보가 훨씬 강력한 방어수단
- **운영**: 전부 **자동갱신 ON + 등록기관 잠금(registrar lock) + WHOIS 프라이버시** 설정. 갱신 실패로 브랜드 도메인을 잃는 사고가 스쿼팅의 최대 공급원

## 6. 이름 결정 후 30일 실행 순서

> 오픈 예정일이 2026-08-04이므로, 아래는 **"이름 확정 = D-Day"** 기준. **[추정]** 순서의 핵심 원칙: **① 흔적이 남지 않는 것부터 ② 되돌릴 수 없는 것 순으로.** 상표 출원 전에 SNS·프레스로 이름을 노출하면 제3자 선출원(무단 선점) 리스크가 생긴다.

### D+0 ~ D+2 — 조용히 선점 (공개 금지)
- [ ] **도메인 먼저 구매**: .com / .net / .app / .kr + 오타 2개. 자동갱신·잠금·프라이버시 설정.

## 8. earthus 자체에 대한 판단 **[추정]**

- 09류는 **"EARTH,US"(2025.07.25 등록)와 칭호 동일** — 출원해도 거절 개연성 매우 높음.
- 42류 공백은 **안전 보장이 아니다.** 42류 SaaS 유사군이 09류 소프트웨어 유사군과 교차 인용되면 동일하게 거절될 수 있다(§1 전제 참조). **42류만 노리는 전략은 유사군코드 교차 확인 전에는 성립 여부를 알 수 없다.**
- 설령 42류 등록에 성공해도 **09류 앱 배포 시 침해 주장에 노출**된다. 웹→iOS/Android 확장이 로드맵이므로 09류 공백은 치명적이다.
- **결론: earthus를 유지하려면 ① 42류 등록 가능성에 대한 변리사 의견서 + ② 선등록권자와의 공존동의(consent) 또는 양수 협상, 두 트랙을 동시에 봐야 한다. 대안 이름 트랙을 병행하는 현재 방향이 옳다.**
