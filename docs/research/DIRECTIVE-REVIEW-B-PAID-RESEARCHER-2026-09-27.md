## 0. 먼저 결론 (다섯 줄)

1. **돈 내는 이유가 문서마다 다르다.** 09-14 요금제는 EXPLORER = 고급 Intelligence + 리포트, PRO = Simulation. 지시서 §11 Q1 은 Intelligence·타임라인·5일 예보를 **무료 v1** 으로 내렸다. 그러면 EXPLORER(₩9,900)에 남는 것은 "확률 %·원인 문장"뿐이다. V7 은 또 다른 사다리(Free/Explorer/Research/Professional)를 쓴다. **세 문서, 세 사다리.**
2. **2027-01-01 에 무엇을 파는지 날짜로 묶여 있지 않다.** §10 의 P4(첫 Simulation)에 날짜가 없고, '먼저 만들 8개' 중 법적으로 1월 1일에 팔 수 있는 것은 **브라우저 즉시형 6개 안팎**이다(아래 1-3).
3. **Windy 는 연 $25 안팎(UNVERIFIED), EARTHUS 는 연 ₩99,000 / ₩290,000 — 3~9배.** 예보 지도로는 이 값을 정당화 못 한다. 정당화 수단은 "한국 자료 + 계산 + 확률의 근거 + 내 기록"이고, 지시서는 앞 둘만 있다.
4. **연구자용 재현 패키지는 "해시는 있는데 원본이 없다".** ECMWF 오픈데이터는 최근 12회(약 2~3일)만 보관(매트릭스 §3 + 레지스트리 일치) → 우리가 입력을 보관하지 않으면 3일 뒤 재현 불가. `simulation_link.py` 에는 컨테이너 digest·수직 기준면 칸이 없고, 사람 승인만 받아 Python 일괄 실행을 기록할 수 없다.
5. **내보내기에서 라이선스가 새어 나간다.** 공공누리 2유형은 2차 가공물에도 '상업 금지'가 따라간다(VERIFIED, kogl.or.kr). 지시서 §13-3 은 인용 문구만 있고 **내보내기 차단 규칙이 없다**(V7 PAY-08 에는 있다).

### 2-1. §13 이 이미 잘한 것
- 세 입구(화면·AI·코드)가 **같은 실행 기록**을 쓴다 — 연구자에게 가장 중요한 설계. `SimulationRunRecord` 검증기(`simulation_link.py`)가 실제로 있고 빈 assumptions/limits·안 한 검증의 결과를 거절한다.

### 2-3. 연구자 MVP (★ 권고 — 이것 없으면 "연구자가 쓸 수 있다"고 말하지 않는다)
1. **엔진 1개 끝까지**: T1 Holland 과거 재현(힌남노) — 입력 IBTrACS(재배포 가능) → 실행 → 관측 비교 채점 → 재현 패키지 → 재실행 허용오차 통과. (가장 짧은 줄: 입력이 미국 정부 저작물이고 식이 공개됨)
2. **재현 패키지 v1**: 입력 조각 보관(불변 S3) + 해시 + 엔진 commit·digest + 매개변수 + seed + 허용오차 + 결과 해시 + 입력별 라이선스.
3. **내보내기**: NetCDF(CF)·COG GeoTIFF·CSV, 모두 crs·수직 기준면·단위 메타데이터.
4. **Python 클라이언트 3함수**: `run()`·`get_result()`·`to_xarray()` + 스윕 1회 승인(`PROJECT_BATCH`).
5. **방법론 페이지 + Zenodo DOI**: 엔진 식·가정·한계·검증 사례·버전 이력, 릴리스마다 DOI.
6. **채점표 공개 페이지**: 표본 수·기준 모형 대비·철회 이력.
7. **라이선스 게이트**: 결과 라이선스 = 가장 제한적인 입력, 상업 내보내기 차단 규칙.
8. **기관 결제**: 웹 결제 + 세금계산서, 연구실 좌석.
