# earthus 발표 자료 (50분)

## 쓰는 법

| 쓸 곳 | 파일 |
|---|---|
| 발표할 때 | `index.html` — 브라우저로 열고 `←` `→` 로 넘긴다 |
| 제출·인쇄 | `earthus-talk.pptx` — 키노트나 파워포인트로 연다 |

**index.html 조작**

| 키 | 하는 일 |
|---|---|
| `→` `Space` | 다음 장 |
| `←` | 이전 장 |
| `A` | 전체보기 (한눈에 훑기) — 주소 뒤에 `?all` 을 붙여도 된다 |
| `⌘P` | 인쇄 / PDF 내보내기 (한 장씩 한 쪽) |

장 번호는 주소에 남는다. `index.html#25` 로 바로 그 장을 열 수 있다.
창 크기에 맞춰 장 전체가 축척되므로 노트북이든 빔프로젝터든 그림이 똑같다.

## 고치는 법

⚠️ **`index.html` 과 `.pptx` 를 직접 고치지 마세요.** 다음에 빌드하면 덮어써집니다.

내용은 전부 `slides.py` 한 곳에 있습니다. 고친 뒤:

```bash
cd docs/talk && python3 build.py
```

두 파일이 같이 다시 만들어집니다.

발표 직전에 다시 세는 걸 권합니다. 세는 방법:

```bash
git rev-list --count HEAD                                   # 커밋 수
find prototype/js -name '*.js' -exec cat {} + | wc -l        # JS 줄 수
find aws -name handler.py | wc -l                            # 수집 함수 수
curl -s https://earthus.net/events/seabird.json | head -c 400 # 바닷새 건수
```
