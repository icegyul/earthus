## 3. 덕후 전략 — "API 중계"가 아니라 "분석 상품"

### 원칙 셋
1. **남이 못 하는 것에서 시작한다.** 실시간 API 중계는 누구나 한다. 우리만 가진 것은
   ① 예보검증 아카이브(매일 자람) ② 다기관 교차대조(USGS/EMSC/JMA, NDBC/OSMC)
   ③ 평년 기준선(OISST·kma-normal) ④ 출처 신뢰 브랜드.
2. **과거는 사면 된다.** 우리 아카이브는 3일치지만, 공공 과거 카탈로그를 **일회성 백필**하면
   "과거 대비"를 오늘 팔 수 있다 (IBTrACS 태풍 175년·USGS 지진 수십 년 — 전부 퍼블릭 도메인).
3. **분석은 서버(Lambda 야간 잡), 폰은 그리기만.** 발열 원칙 그대로.

### 페르소나별 계획 (실현성 × 지불의사 순)

#### ⓪ 공통 설계 원칙 — "관측소 입양" (레퍼런스: r/homeassistant 날씨 대시보드)

> 대표님이 공유한 홈어시스턴트 대시보드에서 얻은 교훈 (2026-07-29):
> **덕후에게 밀도는 부담이 아니라 대접이다.** 그 화면이 좋은 이유 다섯 —
> ① 세계가 아니라 "내 것" 한 곳을 깊게 ② min/max 에 찍힌 **시각**까지
> ③ 모든 숫자에 24h 스파크라인 (맥락 없는 숫자가 없다) ④ 풍향 장미 ⑤ 레이더 애니메이션.

- **"내 관측소" 대시보드**: 가까운 관측소(기상청 AWS 736 · METAR 1,900 · 부이 2,400 · 영국 36)를
  '입양'하면 홈어시스턴트식 밀도로 — 현재값 + 24h 스파크라인 + min/max(시각) + 풍향 장미 + 기압 추세.
  우리는 개인 센서 대신 **기상청 분 단위 실측**을 준다 — 저 사람 집 센서보다 기기가 좋다.
- 평년 대비 카드가 "하루 1회 요약"이라면 이건 **"하루 10회 여는 습관"** — 수익화의 전제.
- ⚠️ 기술 전제: kma-aws-min 은 지금 최신 스냅샷만 올린다. 스파크라인에는
  **지점별 24h 순환 버퍼**(Lambda, 야간 잡 아님 — 매분 갱신 시 append)가 필요하다.
- 덕후 화면의 표시 밀도 기본값은 소비자 화면과 **반대로** 잡는다: 빽빽한 게 기본, 접는 게 옵션.

#### ① 기상덕후 — 자산 100%, 즉시 착수 가능 ★최우선
- **예보 리그(모델 성적표)**: kma-verify 가 이미 매시간 예보-실측을 쌓는다.
  주간 "이번 주 예보 성적: 기상청 vs GFS vs ECMWF, 지역별" 리그표.
  **아무도 안 하는 상품이고 우리는 원료가 이미 돈다.**
- **내 지역 평년 대비 카드**: "오늘 서울 +3.2°C, 상위 4% 더움" (kma-normal 1991–2020 가동 중)
- **기록 경신 감지**: 관측소별 최고·최저 경신 시 푸시
- 유료: 관심 지역 주간 리포트 · 검증 상세 · 과거 리플레이(HISTORY cap)

#### ② 지진덕후 — 자산 85%, 백필로 즉시 "과거 대비" 가능
- USGS 전체 카탈로그 백필(퍼블릭 도메인) → **"이 지역 100년 지진사"** 한 장
- 구텐베르크-리히터 규모-빈도 곡선 · 오모리 여진 감쇠 추적(본진 뒤 실시간 갱신)
- **기관 대조 리그**: 같은 지진을 USGS/EMSC/JMA 가 몇 분 만에, 얼마나 다르게 발표했나 —
  우리 3중 수집의 자연스러운 상품화
- 유료: 관심 단층·지역 알림 + 여진 추적 리포트

#### ③ 태풍덕후 — 자산 80% + IBTrACS 백필
- **IBTrACS**(NOAA, 175년 전지구 태풍 트랙, 퍼블릭 도메인) 일회성 수집 →
  **"지금 이 태풍과 닮은 역대 태풍 5개"** (경로 유사도 검색) · 그 태풍들의 결말
- 시즌 대시보드: ACE(누적 사이클론 에너지) 실시간 vs 역대 동시점
- 태풍 일생 리플레이(archive cyclone 수집 중) + 우리 예보검증 점수 연동
- 유료: 시즌 리포트 · 유사경로 상세

#### ④ 천체덕후 — 자산 90%, 결제 붙는 즉시 수익화 1순위
- 위성 통과 예보·알람 — **이미 PAID_CAP 에 설계돼 있음** (passes/alarms)
- **"오늘 밤 별 보기 점수"**: 구름예보 × 달 위상 × 광공해(VIIRS) 결합 — 관측 최적 시간대
- 스타링크 트레인 통과 캘린더 · 오로라 남하 알림(SWPC 수집 중) · IMO 유성우 캘린더
- 유료: 통과 알람 · 관측 원정 계획(주말 어디로 가면 맑나)

#### ⑤ 항공덕후 — 자산 70%, 차단 1건 해결 필요
- METAR 1,900공항 보유 → **공항 성적표**: 시정·측풍·돌풍 통계, 풍향 장미,
  "오늘 세계에서 가장 거친 접근"
- ⚠️ 실시간 항적(flight 레이어)은 Lambda Function URL 403(계정 차단) 미해결.
  adsb.lol 은 ODbL 표기 의무. **정시성 데이터는 없다 — 없는 것은 안 만든다.**
- 유료: 내 항공편 추적 + 항로 기상 브리핑(flightSheet 골격 존재)

#### ⑥ 분쟁 모니터 (전쟁덕후) — 신중 설계
- 이미 있는 것: GDELT 분쟁 뉴스 지도 · satcat **military 그룹**(공개 TLE)
- 상품: 군사위성 통과 알림 · 분쟁 지역 뉴스 밀도 추이
- ⚠️ ACLED 상업 라이선스 미해결 — **확인 전 사용 금지(기존 결정 유지)**. UCDP 도 상업 조건 확인 필요
- ⚠️ 프레이밍 원칙: 사상자 수를 게임화하지 않는다. "모니터링·맥락" 톤 고정
- 유료 여부는 보류 — 신뢰 리스크가 수익보다 클 수 있다

#### ⑦ 새덕후·고래덕후 — **v2. 지금은 정직하게 없다**
- eBird: 상업 사용에 Cornell 허가 필요(마스터플랜 기존 확인) · Movebank: 연구자별 라이선스 ·
  OCEARCH: 공개 API 없음 · GBIF: CC0/BY 선별 가능하나 실시간성 없음
- **약속하지 않는다.** 라이선스 회신·파트너십이 먼저다

### 단계 (오픈 8/4 기준)

- **오픈 전**: 덕후 신기능 착수 금지. UX 1·2·3(검색·온보딩·볼거리)만
- **1단계(오픈~2주)**: 백필 3종 + 야간 분석 잡 골격 + 기상·지진 무료 분석 2종
  (평년 대비 카드 · 기관 대조) — 무료로 깔아 신뢰·습관을 만든다
- **2단계(결제 연결 후)**: 천체 알람 유료화(설계 완료분) · 태풍 유사경로 · 주간 리포트 구독
- **3단계**: 항공(차단 해결 후) · 분쟁 모니터(라이선스 회신 후)
- **v2**: 새·고래 (파트너십)

### 가격 감각 (기존 티어에 얹기)
- 무료: 모든 실황 + 분석 **요약** (리그 순위표, 평년 대비 오늘)
- 유료(기존 PAID_CAP 확장): 알림 전부 · 과거 리플레이 · 상세 리포트 · 주간 구독 리포트
- 덕후는 "남보다 먼저 아는 것"과 "과거와 비교하는 것"에 지불한다 — 알림과 히스토리가 곧 상품
