# 날씨 서술 분석 — "왜 이런 날씨인가"를 글로 (2026-07-29)

> 목표 예시(대표님 제시 영상 스크립트): "이중 열돔에서 벗어난 한반도 / 열기 위에 습도 폭탄 /
> 습도가 높으면 땀이 안 말라 체감온도 급상승 / 밤에도 안 빠져 초열대야 / 이 수증기가 물폭탄의 재료 /
> 태풍이 북상하면 폭염을 키우거나 비구름을 만든다"
>
> 이 스크립트가 좋은 이유: **문장 하나하나가 검증 가능한 주장**이다. 형용사가 아니라 기작(機作)이다.
> 우리가 할 일은 각 문장을 **지표 하나**에 대응시키고, 그 지표를 매일 계산하는 것이다.

## 0. 세 층으로 나눈다 — 정직성 구조

바다 리포트와 같은 원칙. 섞으면 "earthus 가 예보한다"가 되어버린다.

| 층 | 무엇 | 예 | 출처 표기 |
|---|---|---|---|
| **① 상태** (우리 계산) | 지금 대기가 어떤 상태인가 — 숫자 | "500hPa 5,913gpm, 평년 대비 +80gpm (상위 5%)" | 자료 출처 |
| **② 기작** (교과서 인용) | 그 상태가 왜 더위를 만드는가 | "고기압 하강기류는 단열승온을 일으킨다" | 방법·문헌 출처 |
| **③ 전망** (기관 인용) | 앞으로 어떻게 되나 | "기상청 중기예보: …" | 기관 출처, 가공 없음 |

⚠️ ②는 **일반 기상학**이라 인용해도 되지만, **우리 사례에 적용한 해석은 ①의 숫자 범위 안에서만** 쓴다.
"열돔 때문에 40도가 될 것이다" ❌ / "열돔 상태이고, 기상청은 폭염경보를 냈다" ⭕

## 1. 스크립트 → 지표 대응표 (전부 자료 확인 완료)

실측 2026-07-29, 한반도 중심(36.5N 127.8E) 기준 — **모든 변수가 실제로 옴**.

| # | 영상 대사 | 계산 가능한 주장 | 지표·임계 | 자료 | 실측 |
|---|---|---|---|---|---|
| 1 | "이중 열돔" | 상층·중층 고기압이 겹쳐 있다 | 500hPa 지오포텐셜고도 + 200hPa 고도(티베트고기압) 동시 상위 | Open-Meteo 기압면 | ✅ 5,913 / 12,498 gpm |
| 2 | "남쪽 수증기 대량 유입" | 가강수량이 평년보다 크게 많다 | TCWV(가강수량) 편차·백분위 | 〃 | ✅ 47.4 kg/m² |
| 3 | "습도 폭탄 → 체감온도 급상승" | 같은 기온에서 체감이 크게 오른다 | 체감온도 **여러 공식 병렬**(아래 §2) | 우리 AWS 736(T·RH) | ✅ 수집 중 |
| 4 | "밤에도 안 빠져 초열대야" | 일 최저기온이 기준 이상 | Tmin ≥ 25(열대야) / ≥ 30(초열대야) | AWS 일최저 | ✅ 수집 중 |
| 5 | "물폭탄의 재료" | 대기 불안정 + 수증기 동시 충족 | CAPE · 리프티드지수 · TCWV | Open-Meteo | ✅ CAPE 1,820 · LI −4.1 |
| 6 | "태풍이 북상하면" | 태풍 위치와 고기압 가장자리 관계 | GDACS 트랙 + 500hPa 능선 위치 | 이미 수집 중 | ✅ |
| 7 | "열돔에서 벗어났다" | 지표가 임계 아래로 내려온 날 | 위 지표들의 **상태 전이 감지** | 위 전부 | — |

⚠️ **7번이 이 상품의 핵심이다.** 매일 값을 보여주는 건 대시보드지만,
**"오늘 상태가 바뀌었다"를 잡아내는 것**이 기사(記事)가 된다. 영상 제목도 "벗어난"이다.

## 2. 여러 공식 대입 — 체감온도가 최적 사례

대표님 아이디어("공식이 여러 개면 대입해서 최종 결론")가 가장 잘 맞는 지점.
체감온도는 **공인 공식이 넷 이상 있고 서로 다른 값을 낸다.**

| 공식 | 기관 | 입력 | 성격 |
|---|---|---|---|
| 체감온도(여름) | 기상청 | T, RH (습구온도 경유) | 국내 폭염특보의 근거 |
| Heat Index | 미국 NWS (Rothfusz 회귀식) | T, RH | 그늘·미풍 가정 |
| Humidex | 캐나다 환경부 | T, 이슬점 | 이슬점 기반이라 다르게 반응 |
| WBGT (ISO 7243) | 국제표준 | T, RH, 일사, 풍속 | 야외활동 지침의 표준 |
| Apparent Temperature | 호주 BoM | T, RH, 풍속 | ⚠️ 방법만 인용, 자료 배제 |

**화면 설계**: 넷을 나란히 + "몇 개가 위험 단계인가"로 결론.
```
체감온도 — 4개 공식 중 3개가 '위험' 단계
  기상청 35.2°C 위험 · NWS Heat Index 40.1°C 위험 · Humidex 43 위험 · WBGT 30.8 주의
```
⚠️ 공식마다 **단위와 척도가 다르다**(Humidex 는 °C 가 아닌 지수). 숫자를 나란히 놓되
**같은 축으로 비교하지 않는다.** 등급(주의/경고/위험)으로만 합산한다.
⚠️ 각 공식의 정확한 계수·임계는 **미조사** — methodology-sources.md 에 항목 추가.

## 3. 알고리즘 — 5단계 (바다 리포트와 같은 골격)

```
① 상태 측정   격자·관측소에서 7개 지표 계산 (매시)
② 평년 대비   같은 날짜 평년·백분위로 "얼마나 이례적인가" (매일)
③ 상태 판정   임계 조합으로 상태 라벨 부여 (매일)
④ 전이 감지   어제와 다른 상태면 = 기사거리 (매일)
⑤ 서술 조립   템플릿 + 출처 3줄 (전이 발생 시 + 주 1회 정기)
```

### ③ 상태 라벨 — 조합 규칙 (초안, 검증 전)

| 라벨 | 조건 | 비고 |
|---|---|---|
| 열돔 | 500hPa Z 상위 10% **연속 3일** | 단일 지표·단일 일자로 부르지 않는다 |
| 이중 열돔 | 위 + 200hPa Z 도 상위 10% | 상·하층 중첩 |
| 습윤 열돔 | 열돔 + TCWV 상위 10% | "열기 위에 습도" |
| 초열대야 | Tmin ≥ 30°C | 기상청 정의 ⚠️ 확인 필요 |
| 호우 잠재 | CAPE ≥ 1000 **AND** TCWV 상위 10% | 둘 중 하나만으론 안 부른다 |

⚠️ **임계값은 전부 잠정이다.** 문헌·기상청 기준으로 교체하기 전에는 화면에 올리지 않는다.
특히 "열돔"은 **공식 기상 용어가 아니라 언론 표현**이다 — 우리가 쓰려면
"우리는 이런 기준으로 열돔이라 부른다"를 화면에 밝혀야 한다. 이게 없으면 지어낸 말이 된다.

### ④ 전이 감지 — 기사가 되는 순간

```
어제: 이중 열돔 + 습윤    오늘: 열돔 해제
  → "한반도가 이중 열돔에서 벗어났습니다" (영상 제목과 같은 구조)
```
전이 종류: 진입 / 해제 / 강화(단일→이중) / 성격 변화(건조→습윤).
⚠️ 하루짜리 변동으로 "벗어났다"고 쓰지 않는다 — **연속 2일** 확인 후 발행.

## 5. 조사 필요 (methodology-sources.md 에 추가)

1. 체감온도 4공식의 정확한 식·계수·등급 임계 (기상청/NWS/캐나다/ISO)
2. 기상청 열대야·초열대야 공식 정의
3. "열돔(heat dome)"의 학술적 정의 유무 — 없으면 우리 기준을 명시적으로 공개
4. 500hPa 지오포텐셜 임계로 아열대고기압을 정의한 문헌 (5880gpm 선의 근거)
5. 상층장 평년값을 얻을 자료원 (ERA5 vs GFS 재분석) + 라이선스
6. **Open-Meteo 상업 이용 조건** — 지금 지오코딩만 쓰지만 예보 변수까지 쓰면 조건이 달라질 수 있음

⚠️ 1~4 완료 전에는 판정 라벨을 화면에 올리지 않는다. 지금 있는 건 원료뿐이고 기준이 없다.
