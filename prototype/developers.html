개발자 API

좌표(위도·경도)를 주면 가장 가까운 대한민국 기상청 관측지점의 현재값과 동네예보를 돌려줍니다. 기상청 API를 그때그때 대신 호출해주는 프록시가 아니라, earthus가 이미 시간 단위로 받아 캐시해 둔 자료를 내드리는 것입니다 — 그래서 응답이 실시간 관측 그 자체보다 최대 1시간 늦을 수 있습니다.

현재 범위(v1): 대한민국만 지원합니다. 전 세계 확장은 검토 중입니다.
키 발급: 아직 셀프서비스 가입은 없습니다. dalur@kakao.com 으로 용도를 적어 보내주시면 키를 발급해 드립니다.
엔드포인트: https://d2cd33drviayl6.cloudfront.net (커스텀 도메인 연결 전까지 이 CloudFront 주소를 그대로 씁니다).

인증

모든 요청에 x-api-key 헤더를 포함합니다. 기본 일일 한도는 1,000회입니다.

GET /v1/health

키 없이 호출 가능합니다. 캐시가 언제 갱신됐는지 확인할 때 씁니다.

curl https://d2cd33drviayl6.cloudfront.net/v1/health

이용 조건

이 API로 받은 값의 저작권과 출처 표시 의무는 데이터 이용약관을 따릅니다. 재배포 시 "기상청" 출처와 관측·발표 시각을 함께 표기해야 합니다. 대량 재판매·경쟁 서비스 구축 목적의 이용은 별도 문의 바랍니다.
