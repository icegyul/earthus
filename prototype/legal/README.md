# 법적 요건 체크리스트

문서 초안은 이 폴더에 있습니다. **문서만으로는 부족하고, 아래 신고·설정이 함께 필요합니다.**
전부 사람이 직접 처리해야 하는 일이라 코드로 대신할 수 없습니다.

> ⚠️ 이 문서는 개발자가 조사해 정리한 것으로 **법률 자문이 아닙니다.**
> 출시 전 변호사 또는 노무·법무 전문가의 검토를 받으세요.

---

## 1. 반드시 확인해야 할 것 — 위치기반서비스사업 신고 ⚠️

**인수인계 문서에 없던 항목입니다.**

앱이 사용자 단말의 위치를 받아 해당 지점의 기상 정보를 보여줍니다.
「위치정보의 보호 및 이용 등에 관한 법률」상 이는 **위치기반서비스사업**에 해당할 가능성이 높습니다.

| 구분 | 내용 |
|---|---|
| 근거 | 위치정보법 제9조 |
| 소관 | 방송통신위원회 |
| 절차 | 위치기반서비스사업 **신고** (허가 아님) |
| 예외 | 개인위치정보를 대상으로 하지 않는 경우 신고 면제 (2021년 개정) |

**쟁점**: 우리는 위치를 **저장하지 않고 실시간 처리만** 합니다. 그래도 "개인위치정보의 이용"에
해당하는지가 판단 지점입니다. 전문가 확인이 필요합니다.

**우회 설계안 (검토 가치 있음)**
- 좌표를 **소수점 1자리로 반올림**해서 처리 (약 11km 격자)
- 기상 정보 용도로는 정확도 손실이 거의 없음
- 개인위치정보성이 약해져 신고 대상에서 벗어날 여지
- 부수 효과: 같은 격자 요청이 캐시되어 **API 호출량과 비용이 크게 줄어듦**

→ 이건 기술적으로도 이득이라 **법적 판단과 무관하게 도입할 가치**가 있습니다.

**추가**: 위치기반서비스사업자는 **「위치기반서비스 이용약관」을 별도로** 두어야 합니다.
일반 이용약관과 다른 문서입니다. 신고 대상으로 확정되면 작성이 필요합니다.

## 4. 필수 고지 사항

전자상거래법 제10조에 따라 **앱 내에서 접근 가능**해야 합니다 (설정 화면 등).

- 상호 / 대표자명 / 사업장 주소
- 사업자등록번호 / 통신판매업 신고번호
- 고객문의 연락처(전화·이메일)
- 이용약관 / 개인정보처리방침

→ `js/config.local.js` 의 `BUSINESS` 항목을 채우면 앱에 자동 표시됩니다.

## 5. 해외 배포 시

앱스토어는 기본이 글로벌 배포입니다. **한국만 배포할 게 아니면** 아래가 걸립니다.

| 지역 | 법령 | 주요 요건 |
|---|---|---|
| EU / EEA | GDPR | 법적 근거 명시, 동의 철회 용이성, 데이터 이동권, DPO 지정 여부 검토 |
| 미국 캘리포니아 | CCPA/CPRA | 판매·공유 거부권(Do Not Sell), 수집 항목 고지 |
| 브라질 | LGPD | GDPR과 유사 |

**초기 대응 권장**: 출시 국가를 **한국(+ 필요 시 일본)으로 제한**해서 시작하고,
사용자가 늘면 지역을 넓히면서 각 법령에 대응하는 편이 현실적입니다.

> 허용하는 문구도 확인하지 못했으므로 유료 상품 재료로 쓰기 전 서면 확인이 필요합니다.
> 2026년 7월부터 6자리 신규 카탈로그 번호는 TLE에 포함되지 않으므로, 궤도와 SATCAT
> 수집을 9자리까지 지원하는 공식 OMM JSON·SATCAT JSON 형식으로 전환했습니다.

## 7. 동의 설계 (구현됨)

개인정보보호법상 **필수 동의와 선택 동의를 반드시 분리**해야 하며,
선택 동의를 거부해도 서비스 이용을 제한할 수 없습니다.

| 항목 | 구분 | 거부 시 |
|---|---|---|
| 이용약관 | 필수 | 가입 불가 |
| 개인정보 수집·이용 | 필수 | 가입 불가 |
| 만 14세 이상 확인 | 필수 | 가입 불가 |
| 위치정보 이용 | **선택** | 위치 검색으로 이용 가능 |
| 마케팅 정보 수신 | **선택** | 제한 없음 |

동의 이력은 `consents` 테이블에 **버전과 시각을 함께** 저장합니다.
동의 사실의 입증 책임은 사업자에게 있으므로, 이 기록은 수정·삭제되지 않도록 설계했습니다.
