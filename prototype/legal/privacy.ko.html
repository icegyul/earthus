Apple 로그인 이용 시 "이메일 가리기(Hide My Email)"를 선택하면 실제 이메일 대신 Apple이 제공하는 익명 전달 주소가 수집됩니다.

나. 서비스 이용 과정에서 자동 생성·수집되는 항목

  • 접속 IP 주소, 접속 일시, 서비스 이용 기록, 기기 정보(OS·앱 버전), 쿠키 및 로컬 저장소 데이터

다. 위치정보 (선택)

  • 단말기의 위치정보(위도·경도)
  • 동의하지 않아도 서비스 이용에 제한이 없으며, 이 경우 위치를 직접 검색하여 이용할 수 있습니다.
  • 위치정보는 기상 정보 표시 목적으로만 사용하며, 회사 서버에 저장하지 않습니다.
  • ⚠️ 다만 그 지점의 기상·해양 정보를 받아오기 위해, 좌표가 이용자의 브라우저에서 기상정보 제공사로 직접 전송됩니다. 회사 서버를 거치지 않습니다.
전송받는 곳국가전송 항목목적
Open-Meteo (Meteoblue AG 등)독일·스위스위도·경도그 지점의 기상·해양 예보 조회

  • 위치 사용에 동의하지 않으면 이 전송도 일어나지 않습니다.
  • BigDataCloud 무료 API는 동의받은 단말의 현재 위치에만 사용합니다. 지구본에서 직접 누르거나 검색한 임의 좌표는 외부로 보내지 않고 앱의 오프라인 지명표로 설명합니다.

라. 자동 번역 (사용자가 번역 또는 미리보기 버튼을 누른 경우)

  • 뉴스 제목 또는 커뮤니티 글의 최대 UTF-8 500바이트와 요청 IP가 이용자의 브라우저에서 MyMemory(Translated S.r.l.)로 직접 전송됩니다.
  • 개발 요청을 입력만 할 때는 전송하지 않습니다. 기계 번역 미리보기 버튼을 직접 누른 경우에만 초안을 전송합니다.
  • MyMemory 약관에 따라 번역 구문이 장기 보관되거나 외부 기계번역 제공자에게 처리될 수 있으므로, 비밀번호·연락처 등 민감한 개인정보를 글에 쓰지 마세요.

마. 이용 행태 정보 (선택)

  • 앱·지구 스타일·AETHERUS 진입, 레이어 켜기/끄기, 근거·활동 프로필·예약 영향 화면 열기, 오프라인 진입과 화면 오류 분류처럼 미리 정한 허용 event와 범주값
  • 함께 저장되는 값: event 시각, 하루 단위로 바뀌는 무작위 세션 식별자, 화면 크기 구간·언어·자료 상태 등 80자 이하의 제한된 범주값

  • 동의하지 않아도 서비스 이용에 아무 제한이 없습니다. [설정 → 약관·동의 관리]에서 언제든 끌 수 있고, 끄면 즉시 수집이 멈춥니다.
  • 끄면 서버에 보관 중이던 본인의 이용행태 event도 삭제됩니다. [설정 → 계정 → 내 데이터 내려받기]에는 삭제 전까지의 본인 event가 포함됩니다.
  • 보유 기간: 수집일로부터 1년. 만료 event는 매일 자동 삭제됩니다.
