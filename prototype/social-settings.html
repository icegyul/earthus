공식 발급 설명서

서비스별로 이렇게 준비하세요.

개발자 앱 생성 → 게시 권한 신청 → OAuth 동의 → 토큰 입력 → 계정 확인 순서입니다.

공식 문서 기준 · 2026-08-12 확인

X OAuth 2.0

  1. X Developer Portal에서 Project와 App을 만듭니다.
  2. User authentication을 OAuth 2.0으로 켜고 earthus 콜백 주소를 등록합니다.
  3. tweet.read tweet.write users.read media.write offline.access 범위로 Authorization Code + PKCE 승인을 받습니다.
  4. 받은 Access Token·Refresh Token·Client ID/Secret을 위에 저장합니다.

X API 사용 등급에 따라 게시량과 비용이 달라질 수 있습니다.

X 공식 OAuth 설명서

Threads Meta

  1. Meta for Developers에서 Threads 사용 사례의 앱을 만듭니다.
  2. Threads 계정을 테스트 사용자 또는 운영 사용자로 연결합니다.
  3. threads_basic과 threads_content_publish 권한으로 사용자 동의를 받습니다.
  4. 장기 토큰으로 교환하고 Threads User ID와 함께 저장합니다.

앱 역할 밖의 계정을 연결하려면 Meta의 권한 검토가 필요할 수 있습니다.

Threads API 공식 문서

Instagram Professional

  1. Instagram 계정을 Business 또는 Creator 계정으로 전환합니다.
  2. Meta 앱에 Instagram 제품을 추가하고 OAuth 리디렉션을 등록합니다.
  3. 콘텐츠 게시 권한을 요청하고 Professional Account ID를 확인합니다.
  4. 사용자 Access Token과 Account ID를 저장합니다.

일반 개인 계정에는 API 게시가 되지 않습니다. 사진 또는 영상이 반드시 필요합니다.

Instagram 게시 공식 문서

Facebook Page

  1. Meta 앱을 만들고 Facebook Login for Business를 구성합니다.
  2. 게시할 Facebook Page에서 관리자 권한을 확보합니다.
  3. pages_show_list pages_read_engagement pages_manage_posts 권한을 받습니다.
  4. Page Access Token과 Page ID를 저장합니다.

개인 프로필이 아니라 Facebook Page에 게시합니다.

Facebook Page 게시 공식 문서

TikTok Direct Post

  1. TikTok for Developers에서 앱을 만들고 Login Kit를 구성합니다.
  2. Content Posting API의 Direct Post 기능을 켭니다.
  3. user.info.basic video.publish 권한 심사를 받고 사용자가 OAuth 동의합니다.
  4. Access/Refresh Token과 Client Key/Secret을 저장합니다.

미심사 클라이언트가 올린 콘텐츠는 비공개로 제한됩니다. 현재 earthus 연결은 영상 게시를 지원합니다.

TikTok Content Posting 공식 문서

LinkedIn Posts API

  1. LinkedIn Developer Portal에서 앱을 만들고 회사 페이지와 연결합니다.
  2. 계정 확인용 openid profile과, 개인 게시의 w_member_social 또는 회사 게시의 w_organization_social 권한을 받습니다.
  3. 3-legged OAuth로 Access Token을 발급합니다.
  4. 게시 주체의 person 또는 organization URN과 지원 API 버전을 저장합니다.

회사 페이지 게시자는 해당 조직의 관리자 또는 콘텐츠 관리자 역할이어야 합니다.

LinkedIn Posts API 공식 문서

YouTube Data API v3

  1. Google Cloud에서 프로젝트를 만들고 YouTube Data API v3를 활성화합니다.
  2. OAuth 동의 화면과 Web application Client를 만들고 콜백 주소를 등록합니다.
  3. https://www.googleapis.com/auth/youtube.upload 범위와 offline access로 동의받습니다.
  4. Access/Refresh Token과 Client ID/Secret을 저장합니다.

2020-07-28 이후 생성된 미심사 API 프로젝트의 업로드는 비공개로 제한될 수 있습니다.

YouTube 업로드 공식 문서

토큰은 만료되거나 사용자가 권한을 철회할 수 있습니다. ‘저장됨’은 원문이 암호화되어 있다는 뜻이고, ‘계정 확인됨’은 그 시점에 공식 API가 응답했다는 뜻입니다. 앱 심사와 플랫폼 이용 요금은 별도입니다.
