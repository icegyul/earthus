# V33 Pleos Safety Integration
- Driving state source must be authoritative and capability-checked.
- UNKNOWN is fail-safe, not PARKED.
- SafetyGate must guard execution paths, not only hide buttons.
- Disaster override outranks local discovery and commercial actions.
- Satellite playback, complex filters, keyboard search, settings and reservation flows are blocked in driving-safe mode.
- Map, current weather, disaster alerts and directions remain available within the approved driving UX.
- Every blocked action must be tested by invoking its underlying command, not merely by checking UI visibility.
