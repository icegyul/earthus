# WONDER EARTH ASSETS v2.0

Real asset package — not a presentation sheet.

- Geographic land outlines: Natural Earth vector-derived.
- Each continent: SVG shape + AVIF paper color + mask + height + normal.
- Oceans: regional AVIF + mask.
- Arctic and Antarctica are separate.
- No clouds, labels, or UI are baked into the base textures.
- SVG is the resolution-safe source for crisp boundaries; AVIF is the lightweight visual material.
- Height/normal are intentionally shallow to support the 2.5D paper-cut look rather than photoreal terrain.
