# WONDER EARTH ASSETS v1.2

실제 구형 지구 적용을 전제로 분리한 Wonder 2.5D 자산.

이번 버전은 실제 지형 형태를 가진 글로벌 topographic visual source를 색상 기반으로 단순화해 종이/구아슈 스타일로 만들었습니다. 구름과 라벨은 포함하지 않습니다.

각 지역은 실제 전체 캔버스를 반복하지 않고 지역 bbox로 crop됩니다. `shape.svg`는 확대 가능한 형태 원본, `color.avif`는 웹 전달용, `mask/height/normal`은 2.5D 제어용입니다.

`height.png`는 아직 스타일용 starter이며, 과학적 DEM이 아닙니다. 최종 시뮬레이션용 terrain은 실제 DEM/해저지형으로 교체하세요.
