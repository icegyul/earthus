## 2. 격자와 측정

캐릭터: 해상도 {1024, 768, 512} × 품질 {75, 85, 92}, RGBA 유지, method 6. 장면: 폭 {1536, 1024, 768} × 품질 {75, 85}, RGB.
PSNR 은 캐릭터의 경우 **알파>0 픽셀만**(투명 영역 색은 보이지 않는다), 같은 해상도로 LANCZOS 축소한 원본 대비. 알파 PSNR 은 전 변형 99 dB(= 무손실 보존).

### 2.3 눈 검수 (contact-sheet.png — 얼굴 부근 256px 을 각 해상도에서 같은 물리 영역으로 1:1)

- **1024 q85**: 종이 결·겹 그림자 보존. q92 와 눈으로 구분 어려움. q75 는 종이 결이 살짝 뭉개짐(해태 갈기).
- **768**: 결이 부드러워지고 외곽 계단이 보이기 시작. DPR 3 폰(374 CSS px × 3 = 1,122 device px)에서는 1.46배 확대돼 흐릿해진다.
- **512**: 외곽이 블록 단위로 깨짐. 근접 화면 불가.
- 전 변형 공통으로 외곽에 **1px 색 테두리 픽셀**이 보인다 — 품질·해상도와 무관하게 나타나므로 **원본 PNG 의 반투명 가장자리 픽셀**(크로마 키 잔여)이다. WebP 손실이 아니다. 1024 에서는 1px 이라 실화면에서 거의 안 보인다. 일괄 변환 때 가장자리 정리(반투명 픽셀의 RGB 를 인접 불투명색으로) 옵션을 둘지는 별도 판단.

## 3. 기준안 (승인 요청)

| 자산 | 기준 | 근거 | 124종 합계 |
|---|---|---|---|
| 캐릭터 | **1024×1024 · RGBA · q85 · method 6** | 무대 캐릭터 높이 ≤ 420 CSS px, DPR 3 폰에서 1,122 device px → 1024 필요. q85 가 q92 대비 −1.6 dB 에 −32% 크기, q75 는 결 손실 | **≈ 10.8 MB** (원본 79.8 MB) |
